# ShuyoNote UX 流程与状态覆盖

> 覆盖 11 条关键用户旅程，每条包含：入口 → 关键路径 → 退出，以及空态/加载态/错误态/边界态。
> 与「可点击原型」中的界面一一对应。

---

## 1. 首次启动 / 空工作区

**入口**：安装后首次打开。

**路径**：
1. 侧边栏为空，主区显示空状态（📝 图标 + 「开始你的第一页」+ 主按钮「新建页面」+ 快捷键提示 `Ctrl+N`）。
2. 点击「新建页面」或按 `Ctrl+N` → 创建无标题页 → 自动打开，标题聚焦。
3. 输入标题与内容 → 顶部保存指示从「保存中…」变为「已保存」。

**状态**：
- **空态**：侧栏「暂无页面」、主区空状态 CTA。
- **加载态**：页面树/内容加载时显示骨架屏（浅灰占位块），而非空白闪烁。
- **错误态**：数据库读取失败 → 顶部错误徽标 + 可重试按钮。

---

## 2. 新建页面 / 文件夹

**入口**：侧栏「新建 ▾」菜单、树项行内 `+`、`Ctrl+N`。

**路径**：
1. 「新建 ▾」→ 下拉选择「📄 新建页面」/「📁 新建文件夹」。
2. 新项插入到当前选中项之后（或根级末尾），进入**行内重命名**态。
3. 输入名称，`Enter` 确认，`Esc` 取消（取消则回退到「未命名」并保留）。

**状态**：
- **空名**：提交空名时静默回退「未命名」。
- **错误态**：创建失败 → toast「创建失败」。

---

## 3. 编辑笔记（核心）

**入口**：点击侧栏页面。

**路径**：
1. 打开页面 → 面包屑显示层级路径，标题区可编辑。
2. 正文输入支持 Markdown 快捷（`#`、`-`、`> `、`` ` ``、`[]` 等）与 `/` 斜杠菜单。
3. 输入 `/` → 弹出 slash 菜单（标题/正文/引用/Callout/代码/待办/列表/分隔线/表格），`↑/↓` 选择、`Enter` 确认、`Esc` 关闭。
4. 悬停某块 → 左侧出现 `⋮⋮` 手柄 → 按住拖拽到目标块 → 出现插入指示线 → 松手完成排序。
5. 粘贴图片 → 自动入库（附件存储）。
6. 内容变更 600ms 防抖自动保存。

**状态**：
- **空态**：空页显示占位「输入内容，或使用 / 命令 / Markdown 语法…」。
- **加载态**：切换页面时显示骨架屏。
- **保存中/已保存/失败**：顶部指示器三态；失败转为「保存失败，点击重试」。
- **错误态**：Lexical 状态损坏 → ErrorBoundary 兜底显示错误信息，不白屏。
- **边界态**：拖拽块到自身 → 不动作；拖到列表内 → 作为顶层块插入。

---

## 4. 组织内容（树拖拽排序）

**入口**：侧栏树项。

**路径**：
1. 拖拽树项到另一项上/下 → 计算 `sort_order` 插入。
2. 拖到文件夹 → 变为其子节点；拖到两个兄弟之间 → 改变顺序。
3. 双击 → 行内重命名。

**状态**：
- **拖拽反馈**：目标行显示插入指示线（上/下半区），源行半透明。
- **边界态**：拖到自身 → 不动作；跨层级循环（父拖到子）→ 拒绝并提示。

---

## 5. 看板视图

**入口**：侧栏「📋 看板」。

**路径**：
1. 按标签分列，每列显示卡片（页面标题）。
2. 拖拽卡片到另一列 → 更新该页标签（`moveCard`）。
3. 点击卡片 → 打开页面。

**状态**：
- **空态**：无标签时单列「未分类」+ 提示；列内空显示「拖拽卡片到这里」。
- **加载态**：列数据加载中显示骨架。
- **拖拽反馈**：目标列高亮（`--accent-soft` 背景 + 边框）。
- **错误态**：移动失败 → 卡片弹回 + toast。

---

## 6. 全局搜索

**入口**：侧栏搜索框（或 `Ctrl+K` 后输入 `>` 触发搜索模式）。

**路径**：
1. 输入关键词 → 200ms 防抖 → 返回结果列表（标题 + 高亮片段）。
2. 点击结果 → 打开页面，并保留搜索词用于编辑器内高亮。
3. 支持中文（FTS5 + trigram）。

**状态**：
- **空态**：无关键词 → 无下拉；无结果 → 「无结果」。
- **加载态**：「搜索中…」。
- **错误态**：搜索失败 → 「搜索失败」。
- **边界态**：输入为空 → 关闭下拉。

---

## 7. 编辑器内查找（Ctrl+F）

**入口**：`Ctrl+F`。

**路径**：
1. 右上角弹出查找栏（输入框 + `n / m` 计数 + ↑↓ 按钮 + 关闭）。
2. 输入即高亮所有命中（CSS Custom Highlight，不污染编辑器状态）。
3. `Enter`/`↓` 下一个，`Shift+Enter`/`↑` 上一个；当前命中用更强高亮。
4. `Esc` 或 `×` 关闭并清除高亮。

**状态**：
- **无命中**：计数 `0 / 0`，↑↓ 禁用。
- **边界态**：空关键词 → 清除高亮。

---

## 8. 标签与反向链接

**标签**：编辑区底部 TagBar。
1. 输入标签名 `Enter` 添加；点击 chip 的 `×` 移除。
2. 侧栏「标签」区按标签过滤页面树。

**反向链接**：编辑区底部。
1. 显示所有引用当前页的页面标题；点击跳转。
2. 无反向链接时不渲染该区块。

**状态**：
- **空态**：无标签时 TagBar 仅显示「添加标签…」输入。
- **错误态**：添加/移除失败 → toast。

---

## 9. 版本历史

**入口**：编辑区顶部「历史」。

**路径**：
1. 点击 → 弹出历史列表（时间 + 内容预览）。
2. 点击「恢复」→ 二次确认 → 恢复到该版本（当前内容被覆盖）。
3. 恢复成功后刷新当前页。

**状态**：
- **空态**：「暂无历史版本」。
- **加载态**：列表加载中显示占位。
- **错误态**：恢复失败 → toast。
- **边界态**：恢复属于破坏性操作，必须二次确认。

---

## 10. 回收站

**入口**：侧栏「回收站」。

**路径**：
1. 弹出已删除项列表（图标 + 标题）。
2. 「恢复」→ 回到页面树；「删除」→ 二次确认后彻底删除（不可恢复）。

**状态**：
- **空态**：「回收站为空」。
- **错误态**：恢复/删除失败 → toast。

---

## 11. 备份 / 恢复 / 同步 / 主题

**备份**：侧栏「备份」→ 系统保存对话框选择 `.zip` 路径 → 导出 → toast 显示路径与大小。
**恢复**：侧栏「恢复」→ 选择 `.zip` → 二次确认（覆盖全部数据）→ 导入 → 刷新。
**同步**：侧栏「同步」→ 填写服务器地址 + 可选 token → 保存 / 立即同步 → 显示「上传 N / 拉取 N」。
**主题**：侧栏 ☀️/🌙 按钮循环「跟随系统 → 亮色 → 暗色」。

**状态**：
- **备份**：空路径取消 → 不动作；成功 toast。
- **恢复**：必须二次确认；失败 toast「导入失败」。
- **同步**：未填地址禁用「立即同步」；同步中按钮转「同步中…」并禁用；成功/失败 toast。
- **主题**：切换即时生效，持久化到 localStorage，`data-theme` 驱动。

---

## 12. 多窗口

**入口**：树项行内「⧉ 在新窗口打开」。

**路径**：打开独立窗口渲染单页编辑器（`?page=<id>`）。

**状态**：独立窗口无侧栏，保留命令面板；关闭不影响主窗口。

---

## 统一交互约定

- `Esc` 关闭最上层弹层（命令面板 / 弹层 / 查找 / slash 菜单）。
- 破坏性操作（删除、恢复版本、导入备份、清空回收站）一律二次确认。
- 所有后台操作（保存/同步/备份/导入）结束都有 toast 反馈。
- 焦点环、键盘可达贯穿所有可交互元素。

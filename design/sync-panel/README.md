## 怎么重新生成

```bash
python3 design/sync-panel/draw-sync-panel.py
```

- ⭐ 脚本**自己探测中文字体**（候选列表见文件头）✓ —— ⛔ **找不到就明确报错退出** ✗，**不会静默画出满屏方框** ✓
- ⭐ 每张 `save()` 会打印**它自己的字形检查**；收口时若有任何一张缺字形 ⇒ **非零退出** ✓
  ⇒ ⛔ **不要提交带方框的图** ✗
- ⚠️ 预期输出：10 行 `saved … ｜ 字形检查: 干净（无缺字形）` ＋ `字形闸门：10/10 干净 ✓`，**exit 0** ✓

## 画图的技术约定（踩过的坑，别重犯）

```text
· ⛔ PingFang.ttc 在 Pillow 下打不开（cannot open resource）⇒ 全渲染成方框 ✗
  ⇒ 用 Hiragino Sans GB.ttc（macOS）且 index=0 ✓；脚本按候选列表探测 ✓
· ⛔ emoji/dingbat 在该字体里没有字形 ⇒ 源码里用【禁】【错】【对】【注意】【要点】等**纯中文** ✓
  （机器核查：与该字体渲染 U+E000 的位图做签名比对 ⇒ 相同即缺字形 ✓）
· ⭐ 画完必须自己看一遍（每张都看过：无方框、无重叠、无压框 ✓）
· 画幅 2000×1400 ／ 白底浅灰卡 ／ 蓝色主按钮 ／ 绿黄红状态框（照既有那套风格 ✓）
```

## ⭐⭐ 每张图必须先回答的「三问」

> 由两次真事故换来 ✓（都属同一形状：**按新口径改某一张，却把旧的东西漏掉** ✗）：
> · 曾把「**个人空间**」画成"绑服务器" ✗ —— 而口径是**个人空间不能绑服务器** ✓
> · 曾**只画团队空间**、把「**个人空间**」整套漏掉 ✗ —— 而**免费版用户看到的就是那一套**（产品主路径 ✗）

动笔前，每张图先写下这三行：

```text
① 这张图覆盖**哪几类对象**？（例：个人空间 ／ 团队空间 ／ 团队空间下的不同服务器 ✓）
   ⚠️ 少一类 ⇒ 就是漏 ✗
② 这张图覆盖**哪几种状态**？（例：已同步 ／ 登录已过期 ／ 未在当前组织下 ／ 已解绑 ✓）
   ⚠️ 只画一种状态 ⇒ 读的人会以为"就长这样" ✗
③ 口径出自**哪一条**（本文档体系内可达的出处 ✓）
```

⇒ **硬规矩**：

- ⭐ 凡"按新口径改某一张" ⇒ **先回头列一遍：这个界面一共有几类对象／几种状态** ✓
  ⛔ **不许只改被点到的那一格** ✗
- ⚠️ 若某张**只覆盖一类**（例：只画团队空间 ✓）⇒ ⭐ **必须在图上明写**「本图只画团队空间」✓
  ⛔ **不许让读者以为那是全部** ✗

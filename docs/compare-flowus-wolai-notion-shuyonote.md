# FlowUs vs Wolai vs Notion vs ShuyoNote

> 「Notion 类」块编辑产品四款横向对比：Notion（国际标杆）、FlowUs 息流、Wolai 我来（国产云端替代）、ShuyoNote（本地优先）。与前一份 [Obsidian / 思源对比](compare-obsidian-siyuan-shuyonote.md) 共同构成竞品全景。

## 1. 一句话定位

| 产品 | 定位 | 数据形态 | 模式 |
|------|------|----------|------|
| **Notion** | 云端 All-in-one 工作空间（国际标杆） | 云端 | SaaS 订阅（免费 + 付费） |
| **FlowUs 息流** | 国产 All-in-one 云端协作工作空间 | 云端 | SaaS 订阅（免费 + 会员） |
| **Wolai 我来** | 国产云端块编辑器 + AI 协作 | 云端 | SaaS 订阅（免费 + 会员） |
| **ShuyoNote** | 本地优先的 Notion 式块编辑 + 关系型工作台 | 本地 SQLite | 开源（MIT）/ 自托管 |

## 3. 核心差异洞察

### 3.1 云端 vs 本地是根本分界

- **Notion / FlowUs / Wolai**：云端 SaaS，强在**实时协作、AI、跨端无缝**，弱在**数据主权、离线、订阅费用**。
- **ShuyoNote**：本地优先，强在**隐私、离线、数据自持、免费开源**，弱在**协作、AI、跨端**。

### 3.2 「数据库」是四者共同主线

四者都围绕「块 + 属性 + 数据库视图」构建——这正是 Notion 品类（含其国产替代）的核心价值，也是 ShuyoNote 已补齐的能力。

### 3.3 ShuyoNote 的差异化组合

ShuyoNote 是「**本地优先 + Notion 式块编辑/数据库 + 块级引用/关系图**」的组合：

| 借鉴自 | 能力 |
|--------|------|
| Notion 品类 | 块编辑器、属性 + 数据库视图（表格/画廊/看板） |
| 思源 / Obsidian | 块级引用/嵌入、块级反链、关系图、`[[双链]]` |
| 自研 | Tauri + SQLite + FTS5 中文检索、自建同步、本地离线 |

## 4. 选型建议

| 需求 | 推荐 |
|------|------|
| 团队实时协作 + AI + 全平台 + 国际化 | **Notion** |
| 团队协作 + 国内云 + 类 Notion | **FlowUs 息流 / Wolai 我来** |
| 本地优先 + 隐私离线 + 免费开源 + 桌面单机/自建同步 | **ShuyoNote** |

## 5. 对 ShuyoNote 的启示

- **协作是云端竞品的核心壁垒**：ShuyoNote 若要覆盖团队场景，需引入端到端加密的实时/异步协作（长期方向）。
- **AI 是当前主流卖点**：本地 AI（本地模型接入）可作为差异化，避免云端数据外泄。
- **数据库能力已对齐**：ShuyoNote 的数据库视图（表格/画廊/看板）已追上品类核心，差距主要在协作、AI、移动端、生态。

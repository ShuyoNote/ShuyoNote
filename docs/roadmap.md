# ShuyoNote 路线图

> 基于三方对比（见 [compare-obsidian-siyuan-shuyonote.md](compare-obsidian-siyuan-shuyonote.md)）梳理的下一阶段演进路线。按「价值 ÷ 工程量」排序，短期聚焦补平关键短板，中长期对标竞品上限。

## 1. 现状（已实现）

- **块编辑器**：Lexical 12 种块类型、表格交互（悬浮工具栏 / 列宽 / 选区）、图片/视频/附件、块拖拽排序、斜杠菜单、Markdown 快捷输入
- **块级引用/嵌入/反链**：稳定 `blockId`、`((id))` 块引用、`{{id}}` 块嵌入、块级反链面板、目标缓存刷新
- **属性 + 数据库**：8 类型属性 + 页面属性面板 + 数据库页（表格 / 画廊 / 看板 三视图）+ 列/选项管理 + 标签互通
- **关系图**：力导向图、块级图层、局部/缩放平移/聚焦、标签与属性过滤着色
- **组织与检索**：页面树 / 文件夹、标签、看板、FTS5 全文搜索（含 `prop:` 属性语法）
- **数据安全**：自动保存、版本历史、回收站、整库备份
- **同步**：自建 sync-server（outbox 变更日志 + LWW + 附件内容寻址）
- **体验**：暗色模式、命令面板、多窗口、快捷键

## 2. 下一阶段优先级

| 优先级 | 方向 | 对标 | 理由 |
|--------|------|------|------|
| **P0** | Markdown 无损往返 | Obsidian 存储哲学 | 消除「格式锁定」顾虑，是当前最大信任短板 |

## 3. 里程碑规划

### M1 — Markdown 无损往返（P0）✅ 核心已实现

- **目标**：Markdown 导入 → 块编辑 → 导出，不丢信息；探索「Markdown 为真相源、JSON 为缓存」的混合存储。
- **要点**：
  - 建立 Lexical 节点 ↔ Markdown 的**双向确定性映射**（标题/引用/代码/列表/表格/图片/块引用/块嵌入/Callout）。
  - 覆盖 `[[标题]]` / `((块ID))` / `{{块ID}}` / `#标签` 等语法。
  - 往返测试：`md → json → md` 与 `json → md → json` 均幂等。
- **验收**：导入再导出 100% 一致（diff 为空）；块引用/嵌入/表格/图片在往返后仍有效。
- **实现**：`src/editor/markdownTransformers.ts` 的 `SHUYONOTE_TRANSFORMERS` 已覆盖 图片 `![]()`、视频 `!video()`、块嵌入 `{{id}}`、块引用 `((id))`、分隔线 `---`、待办 `- [ ]`、Callout `> [!NOTE]`、Markdown 表格；补齐 Lexical 0.49 默认 `TRANSFORMERS` 不含表格/待办/分隔线/图片的缺口。往返一致性待运行时验证。

### M2 — 端到端加密（P0）

- **目标**：同步内容在本地加密后上传，服务端不可读。
- **要点**：密钥派生（Argon2/口令）+ 对称加密（XChaCha20-Poly1305 或 AES-GCM）；`content_json` / `content_text` / 附件加密后同步；密钥仅存本机。
- **验收**：开启加密后，sync-server 侧数据为密文；换机凭口令恢复。

### M3 — 主题 / 外观自定义 + 插件雏形（P1）

- **目标**：用户可切换主题（CSS 变量覆盖）、自定义强调色/字体；命令面板插件可「安装/启用/禁用」。
- **要点**：主题 = 一套 CSS token 覆盖；插件 = 打包的命令清单 + 元数据，本地目录扫描加载。
- **验收**：导入主题后全局配色即时切换；安装插件后命令出现在面板。

### M4 — 属性驱动仪表盘聚合（P2）✅

- **目标**：数据库页支持分组计数/数值汇总（如「状态=进行中 ×3」）。
- **要点**：`query_database` 增加聚合模式（group-by 计数、number 求和/平均）；前端汇总条/统计卡。
- **验收**：数据库页顶部显示各 select 值的计数与 number 列汇总。
- **实现**：`DatabaseView` 顶部汇总条——select 列按值着色计数徽标、number 列合计/均值（纯前端从行数据聚合，尊重筛选）。

### M5 — PDF 导出（P2）

- **目标**：页面/数据库导出为 PDF。
- **要点**：复用 HTML 导出 + Tauri 系统打印 / 无头渲染。
- **验收**：导出 PDF 与页面渲染一致。

### M6 — 移动端适配（P2，长周期）

- **目标**：Tauri 移动端（iOS/Android）可用。
- **验收**：核心编辑 / 浏览 / 搜索在移动端可用。

### M7 — 数据库视图扩展（列表 / 日历 / 时间轴 / 目录）（P2）

- **目标**：数据库页除表格 / 画廊 / 看板外，新增 **列表**、**日历**、**时间轴**、**目录** 视图（对标 Wolai / FlowUs）。
- **要点**：每种视图 = 同一行数据的另一呈现（前端渲染，复用 `query_database`）；日历 / 时间轴基于 `date` 属性落格，目录基于页面层级。
- **验收**：视图切换实时重排；日历按 date 属性落格；时间轴 / 目录正常展示。

### M8 — 新页面引导层（P3）

- **目标**：空白「新页面」提供「页面 / 数据库 / 从模板库 / 导入 / AI 创作」入口，而非直接进空白编辑器（对标 Wolai / FlowUs 首屏）。
- **要点**：空状态引导组件；模板库入口；AI 创作入口（预留）。
- **验收**：新页面首屏显示引导选项，点击直达对应创建流程。

## 4. 竞品差距跟踪

| 维度 | 当前差距 | 计划 |
|------|----------|------|
| 数据可移植性 | 格式锁定 | M1 Markdown 无损往返 |

| 扩展性 | 仅命令注册表 | M3 主题 + 插件雏形 |
| 聚合能力 | 无汇总 | M4 仪表盘聚合（已实现） |

| 导出 | 缺 PDF | M5 PDF 导出 |
| 多端 | 仅桌面 | M6 移动端 |

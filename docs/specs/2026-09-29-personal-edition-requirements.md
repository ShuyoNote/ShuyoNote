# 个人版 —— **需求（定死）**

> 由来：owner 2026-09-29「**个人版和企业版的需求定死**」
> 依据：`edition-boundary`／`nearby-devices-spec` §13–§17／`virtual-lan-requirements-spec`／
> `personal-edition-vs-competitors`。
> ⚠️ 与 [`enterprise-edition-requirements`](2026-09-29-enterprise-edition-requirements.md) **成对**：两版的分界是
> **「有没有第二个人」**（规格 §13.10.5）。

---

## 0. 定位（一句话）
```text
**个人版 = 只有我一个人（设备可以很多）用的、不经过任何服务器的本地优先笔记。**
  · 空间 = **个人空间**｜连接 = **设备直连**（局域网／虚拟局域网）｜**不过服务器**
  · 动作 = **配对**（＋**必须验证**：配对码人核对）｜**不做邀请**（§14）
  · 隐私 = **数据根本不出去**
```

## 1. 需求（**MUST** —— 定死，逐条可判）
| # | 需求 | 验收 |
|---|---|---|
| **U1** | ⭐ **配对进设备直连**（今天**没有入口**） | 在 A 上点「把这台设备接进来」⇒ B 上也确认／两端比对同一串码 ⇒ 接上 |
| **U2** | ⚠️ **配对必须有人验证**（配对码**由人核对**，**不许跳过**、**不许机器自动通过**） | 确认那一步必须用户触发；**无"自动通过"分支** |
| **U3** | **两端都显示同一串码**，且**两边不一样 ⇒ 停下**（提示可能有中间人） | 人为构造不一致 ⇒ 界面给出"停"的提示 |
| **U4** | **码长按成文判据**（`CHECK_CODE_MIN_BITS=60`）**不许为好看缩短** | 渲染位数与常量一致；那条测试在岗 |
| **U5** | ⭐ **地址自动**（绑通配 ＋ 系统枚举本机内网地址） | 绑 `0.0.0.0:<port>` **不再被拒**；换网后**仍能报出可达地址** |
| **U6** | ⭐ **端到端自动**（配一次，之后全自动） | 配对后重启两台设备 ⇒ **无需任何操作**即同步 |
| **U7** | **局域网自动发现 ＋ 按节拍同步** | UDP 广播发现；节拍默认 **5 秒**（可调） |
| **U8** | ⭐ **一个窗口服务多空间** | 三个空间 ⇒ **一个**端口；各空间拉取**互不影响** |
| **U9** | ⚠️ **口令强度要求** ＋ **如实说明"未加密时它是唯一防线"** | 弱口令被拒并给可操作理由；文案说清 |
| **U10** | **静态加密可选**（第二道门，已有） | 可开可不开；开了多一层保护 |
| **U11** | **逐台解除配对** | 删掉某台的"设备对秘密"⇒ **那台连不上**，**不必给所有设备换口令** |
| **U12** | **虚拟局域网可用**（进阶路径） | 在 VPN 网段里两台设备可配对同步（文档＋文案指引） |
| **U13** | **不许声称"系统能识别是不是你的设备"** | 文案只许说"已配对"（动作），不许说"已确认是您的设备"（判定） |

## 2. 明确**不做**（WON'T —— 定死）
```text
❌ **不做邀请**（owner §14 裁定：设备直连只做配对）
❌ **不做多人协作**（有第二个人 ⇒ 走企业版 —— 那是分界线）
❌ **不做服务器同步**（owner 重申：同步服务器不提供个人版）
❌ **不提供成员/权限/审计**（个人场景不需要，也没有权威可依）
❌ **不做"不过服务器的多人协作"**（留口子代价 ≈0 但 owner 已定"不留口子"）
```

## 3. 不变式（**要判据的**）
```text
**INV-PER-no-server** 个人版**不联系任何服务器**（含遥测）。
**INV-PER-pairing-requires-proof** 配对**必须有两端对上的验证**（人核对），**不许自动通过**。
**INV-PER-pairing-needs-no-acceptance** 配对**不需要对方"社交同意"**，
  ⚠️ **但需要"两端都对上"这一步** —— 两者不同（§16.1 纠正过）。
**INV-PER-unencrypted-needs-strong-secret** 未加密 ⇒ 口令是**唯一**防线 ⇒ 必须强度要求＋文案说清。
**INV-PER-address-survives-network-change** 绑定写法经得起换网（通配＋枚举），换网时**如实提示**。
**INV-PER-own-device-cannot-be-proven** **不许**声称系统能识别"是不是你的设备"。
```

## 4. 一句话
```text
**个人版定了：**配对进设备直连（**带人验证**）＋地址自动＋一窗多空间＋口令强度＋可选加密＋逐台解除，
**不过任何服务器**；而**不做**邀请、多人、服务器同步、成员权限。
```

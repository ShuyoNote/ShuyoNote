## 0. ⚠️ 先说清一件事：**它们没有"不过云的个人版"**
```text
WPS 个人版 / 腾讯文档 / 飞书 —— **全都过它们的云**（文档存在服务端、账号体系在服务端）
⇒ ⇒ 所以我们说的"个人版"（**设备直连、不过服务器、可 E2E**）与它们**不是同一类东西**。
⇒ ⇒ ⇒ 下面的对比是"**我们的个人版 vs 它们的个人/免费档**" ——
   而**最本质的一格（过不过云）它们结构上就做不到**（见 §2）。
```

## 2. ⭐ 我们个人版**结构性赢**的（它们做不到）
```text
⭐ **不过云**（数据根本不经过任何服务商）
⭐ **端到端加密**（服务商不存在，谈不上"看得见"）
⭐ **同网段 <10ms**（不走公网）
⭐ **无需账号**（不注册就能用）
⭐ **无容量配额**（自己盘）
⭐ **数据主权**（全在自己设备上，可退出）
✅ **离线**（本地优先）
```
**⇒ ⇒ 这七格里有六格是【同一个根】：数据不出去。**
```text
**"数据不出去"这一个决定，同时买到了：不过云／不可见／E2E／<10ms／无需账号／无配额／数据主权。**
⇒ 而这正是它们**结构上做不到**的 —— 它们的产品形态**就是**"把数据放到云上"。
```

## 3. ⚠️ 我们个人版**弱**在哪（诚实）
| 弱项 | 说明 |
|---|---|
| **跨地点要自搭 VPN** | 不过云的直接代价 —— 这是"我们服务器本来能提供的价值"被主动放弃 |
| **弱口令风险** | ⚠️ **未加密空间的口令就是唯一防线**；且用户**不会知道自己其实是公开的** |
| **配对靠人核对** | ⚠️ 20 位码长（60 bit 判据）⇒ 易被跳过 ⇒ **这是人因风险** |
| **无多人协作** | 个人版不做（多人走团队版）—— 而它们免费档就能分享 |
| **移动端/生态** | 远不如它们（模板、素材、插件） |
| **规模上限** | 局域网 5~10 台（同网段）；虚拟网络看 VPN |

## 4. ⭐ 而"最强个人版"要补的四件
```text
① **配对进设备直连**（今天**没有入口** —— 邀请已撤、配对没做）⚠️ **最紧急**
② **地址自动填写**（今天必须手填 IP，换网就失效 —— §13.9 前提一）
③ **口令强度要求** ＋ 如实说明"未加密时它是唯一防线"（§13.8.5）
④ **一个窗口服务多空间**（今天每空间一套配置 ＋ 一个端口 —— §13.9 前提三）
⇒ ⇒ 补完这四件，「配对一次、之后全自动」才真正成立。
```

## 5. 一句话
```text
**我们的个人版与它们不是同一类东西** —— 它们**全都过云**，我们**不过**。
⇒ 所以对比结论是：
  · ⭐ **六格结构性赢**（根都是"**数据不出去**"）：不过云／不可见／E2E／<10ms／无需账号／无配额／主权
  · ✅ **一格能追**（离线）
  · ⚠️ **它们赢的**：跨地点（它们免费，我们要 VPN）／移动端／生态／多人分享
  ⇒ ⇒ 而"最强个人版"要补四件：**配对入口／地址自动／口令强度／一窗多空间**。
```

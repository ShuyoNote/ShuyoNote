## 一、软件概述

ShuyoNote 数友笔记（以下简称"本软件"）是一款**本地优先**的知识管理与笔记软件。
它的设计出发点是一句话：**你的数据应该留在你自己的设备上**。

与常见的云端笔记不同，本软件的笔记、附件与加密密钥默认都保存在用户自己的设备上；
需要多设备使用时，用户可自行部署同步服务端，而非依赖厂商的云。因此本软件特别适合：

- 关注数据主权、不愿把私人笔记交给第三方云服务的个人用户；
- 需要离线写作（飞机、内网、断网环境）的用户；
- 需要长期保存与自行备份、不希望被平台锁定的用户。

**主要能力**（详见第三章）：块式文档编辑、多工作空间、多种数据库视图、双向链接与关系图、
PDF 阅读与批注（含离线文字识别）、文件管理、模板、插件扩展、邮件聚合、多设备同步、
整库备份与恢复。

## 三、主要功能与操作流程

### 3.1 文档编辑

采用块（Block）式编辑：每个段落、标题、列表、表格、代码块都是一个可独立操作的块。

- 输入 `/` 唤起命令菜单，可插入标题、列表、待办、表格、分栏、代码块、公式、绘图、引用等；
- 支持 Markdown 语法快捷输入（如 `# ` 变标题、`- ` 变列表）；
- 支持**无损 Markdown 往返**：导入 Markdown 后再导出，结构不丢失；
- 公式：块级 `$$…$$` 与行内 `$…$`，渲染为 KaTeX；
- 绘图：集成 Excalidraw（手绘）与 mermaid（流程图/思维导图，文本转图）；
- 选中文字可进行加粗、高亮、颜色、链接等格式操作。

【待补截图】编辑界面与 `/` 命令菜单

### 3.2 多工作空间

用户可建立多个互相隔离的工作空间（如"工作""个人""读书笔记"）。

- 每个工作空间的数据**物理隔离**，可单独备份、单独搬移；
- 可对**单个工作空间单独开启加密**，其余空间保持明文，互不影响；
- 切换空间后，搜索、反链、标签等结果只来自当前空间。

【待补截图】空间切换菜单

### 3.3 数据加密

- 用户设置口令后，数据库文件以 **SQLCipher** 整体加密；
- 加密密钥由口令派生，**不落盘**，仅在该次使用期间驻留内存；
- 支持"锁定/解锁"：锁定后即使程序在运行，数据也不可读；
- 关闭加密可将数据转回明文（需再次输入口令）。

【待补截图】加密设置与解锁界面

### 3.4 属性与数据库视图

在普通文档之外，可把页面当作数据表来用：

- 为页面定义属性（文本、数字、日期、单选、多选、关联等）；
- 同一批数据可用**表格 / 画廊 / 看板 / 列表 / 日历 / 时间轴**等多种视图呈现，并保存视图；
- 支持跨库关联与汇总（rollup）、公式列；
- 适合做读书清单、项目看板、内容排期等。

【待补截图】数据库视图（表格与看板各一张）

### 3.5 双向链接与关系图

- 用 `[[页面名]]` 建立链接，页面底部自动列出**反向链接**；
- 支持别名 `[[标题|别名]]` 与块级引用 `[[页面#块]]`；
- 关系图按标签/属性着色分组，支持关键词高亮，用于发现笔记之间的关联；
- 支持"未链接提及"（提到但没加链接的页面）。

【待补截图】反向链接区与关系图

### 3.6 PDF 阅读与批注

内置 PDF 阅读器，无需外部软件：

- **连续滚动**阅读整篇，支持缩放与"适配页宽"；
- 批注工具：高亮、画笔、便签，批注随页面保存；
- 扫描件（无文本层的 PDF）可调用**离线文字识别**进行划词；
- 可把选中内容一键**摘录成块**写入笔记，并自动生成回链，之后可被搜索与反链追踪；
- AI 辅助：划选内容请 AI 总结、对整篇文档提问、一键生成目录、系统朗读。

> 说明：文字识别所需的中文/英文语言包约 30 MB，**首次使用需联网下载一次**，
> 之后永久离线可用。

【待补截图】PDF 阅读器与批注工具条

### 3.7 文件管理（文件夹即网盘）

- 附件按**内容寻址**存储，同一文件重复上传只占一份空间；
- 文件夹同时承载页面与文件，支持拖拽移动、批量操作、在线预览；
- 保留文件版本历史，可回溯；
- 存储面板按空间统计占用，可清理回收站、孤立附件与旧版本。

【待补截图】文件夹视图与存储面板

### 3.8 模板

把常用结构保存为模板（含数据库模板），之后一键创建带内容的页面。

【待补截图】模板中心

### 3.9 插件扩展

本软件提供带**权限模型**的插件体系，扩展能力而不牺牲安全：

- 插件必须**声明**它需要哪些数据权限并说明理由，用户在启用前能看到完整清单；
- 支持**零代码插件**（只声明主题或界面，不含任何可执行代码）；
- 插件可声明"在什么事件后自动运行"（如页面保存后、同步完成后），同样需用户确认；
- 可从索引地址订阅插件来源，逐个查看来源、签名状态与发布者指纹后再安装；
- 提供应用内校验、日志与"事实清单"（来源、体积、实际权限），便于用户判断。

【待补截图】插件管理面板

### 3.10 邮件聚合（桌面版）

在桌面版中可绑定多个邮箱账号（IMAP），聚合到一个收件箱：

- 多账号合并按时间排序，可按账号或多选筛选，可按月直达；
- 邮件可一键转为笔记或任务；
- 支持发信（SMTP）。

> 该功能依赖桌面系统的 TLS 能力，**不在移动端提供**。

【待补截图】邮件面板

### 3.11 多设备同步与备份

- 支持**自建同步服务端**：用户把同步服务指向自己的服务器，数据不经厂商云；
- 采用"提交序列 + 冲突合并"的方式，多端同时修改也不会丢改动；
- **整库备份 / 恢复**：一键导出全部数据，可在新设备恢复；
- 回收站兜底误删。

【待补截图】同步面板与备份界面

### 3.12 检索与 AI

- 全文检索（支持相关度排序）与语义检索；
- 内置命令面板（快捷键唤起）与完整的键盘快捷键体系；
- AI 能力均为**可选**：需用户自行配置模型端点（支持本地模型），未配置时相关入口不出现；
- AI 写入笔记前会先给出待确认内容，用户确认后才落库。

【待补截图】搜索界面与 AI 面板

## 四、技术特点

- **本地优先架构**：数据默认全部在本地，联网功能均为可选；
- **端到端加密可选**：口令派生密钥，密钥不落盘，支持会话锁定；
- **跨平台一致**：桌面端（Tauri + Rust）与浏览器版共用同一套前端与数据模型；
- **多端形态**：Windows / Linux 桌面版与浏览器版已发布；Android 与 macOS 的代码在同一软件中（见第二章状态）；
- **不收集数据**：不含埋点与第三方统计 SDK，不向厂商回传使用数据。

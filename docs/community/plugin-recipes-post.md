# ShuyoNote 插件配方：第一批 12 个可直接装的插件

这帖只解决一件事：**让你几分钟内挑到能用的插件，并装上**。下面 12 个都是仓库里自带、并且进了回归测试的插件——不是设想，是现在就能跑的东西。每个插件只占几行，你可以直接跳到感兴趣的那一节。

全文没有一个字要你写代码；想自己写的话，最后一节有指路。

## 一、三步装好一个插件

1. 打开「**插件管理 → 打开插件目录**」。
2. 把某个插件目录**整个**复制进去。这一步最关键：**目录名必须与 `manifest.json` 里的 `id` 完全一致**（比如 `weekly-review`），差一个字母就校验不过。
3. 回到插件面板点「**校验**」→ 逐条看清**权限与理由** → 点「**启用**」。

新装的插件**默认未启用**——你点启用之前它什么也做不了。装好之后，命令面板（`Ctrl+K`）里就能搜到它的命令。

## 二、怎么选：按你想做的事跳转

- 定期回看「这段时间写了什么」 → **周回顾**
- 找出该有人看一眼的页面（久未更新 / 没人链过去） → **陈旧页巡检**、**孤立页面巡检**
- 把内容带出去或换个格式（导出 `.md`、CSV → 表格） → **当前页导出 Markdown**、**CSV 转表格**
- 把一次检索的命中整理成一页（资料收集） → **检索汇总**
- 给页面标状态、看最近更新、查后台同步与附件 → **页面状态**、**阅读看板**、**活动摘要**、**附件信息**
- 屏幕看着累 / 要投屏演示 → **护眼主题**、**高对比主题**

## 三、12 个插件

### 周回顾 `weekly-review`

把最近 N 天动过的页面汇成一篇「回顾」草稿（标题清单 + 统计）。

- **权限**：读页面标题与更新时间（`read:pages`）；新建页面（草稿，`write:pages`）
- **用法**：命令面板 → 「生成回顾」，可填**天数 / 条数**；不填就用插件设置里的值

### 陈旧页巡检 `stale-triage`

找出 N 天没更新的页面，批量打 #待整理。

- **权限**：读页面（`read:pages`）；读标签（`read:tags`）；加标签（草稿，`write:tags`）
- **用法**：命令面板 → 「找出久未更新的页面」；一次运行产出多条草稿，汇总成一次确认

### 孤立页面巡检 `orphan-pages`

找出没人链过去的「孤岛」，生成清单草稿。

- **权限**：读页面（`read:pages`）；读反向链接（`read:backlinks`）；新建页面（草稿，`write:pages`）
- **用法**：命令面板 → 「找出孤立页面」

### 当前页导出 Markdown `page-to-md`

把当前打开的页面写成一份 `.md`。

- **权限**：读当前页段落（`read:pages`）；导出文件（`export:files`，**存哪里由你选**）
- **用法**：命令面板 → 「导出：用「当前页导出 Markdown」保存为 .md」；点取消就什么都没写

### CSV 转表格 `csv-table`

选中 `.csv` / `.tsv` → 转成 Markdown 表格放进一篇新页面。

- **权限**：新建页面（草稿，`write:pages`）
- **用法**：命令面板 → 「用「CSV 转表格」导入表格」→ 选文件

### 检索汇总 `search-collect`

用关键词检索本空间 → 整理成一页清单草稿（资料收集时省事）。

- **权限**：读页面（`read:pages`）；新建页面（草稿，`write:pages`）
- **用法**：命令面板 → 「把检索结果整理成一页」

### 页面状态 `page-status`

给当前页一键标状态（待办 / 进行中 / 已完成）。

- **权限**：读属性定义（`read:properties`）；写属性（草稿，`write:properties`）；加标签（草稿，`write:tags`）
- **用法**：命令面板 → 「设置当前页状态」；**属性优先，没有「状态」属性就用同名标签兜底**

### 活动摘要 `activity-digest`

把「同步完成」「附件导入完成」这两件后台事记成一条摘要：日志里能看到每一条明细，同步真有推拉时提示一次。

- **权限**：插件自己的日志与私有数据（`kv:own`，**读不到你的笔记**）
- **用法**：事件 `sync.completed` / `import.finished`；命令面板 → 「看活动摘要」

### 附件信息 `attachment-report`

在文件列表里右键 → 报告这个附件的名字 / 大小 / 类型，以及它在所属页里排第几。

- **权限**：只读附件元数据（`read:files`）
- **用法**：文件列表 → 右键任一项 → 「插件命令」

### 阅读看板 `reading-board`

一张「最近更新」浮层表（天数 / 条数**在设置里调**）+ 一个「本月新增」**右侧常驻面板**。

- **权限**：无（`runtime: declarative`，零代码声明式视图）
- **用法**：命令面板 → 「插件视图：最近更新」；右侧竖条 → 「本月新增」

### 护眼主题 `eye-care-theme`

暖白背景 + 降蓝正文，长时间读写不那么累。

- **权限**：无（`runtime: declarative`，零代码主题）
- **用法**：启用即生效；停用即恢复

### 高对比主题 `high-contrast-theme`

纯黑纯白，投屏 / 投影 / 老花时看得清。

- **权限**：无（`runtime: declarative`，零代码主题）
- **用法**：启用即生效；停用即恢复

## 四、安全与边界

- **新装插件默认未启用。** 装进去不等于授权——你看完权限和理由，自己点「启用」它才开始工作。
- **写操作先出草稿。** 新建页面、写属性、加标签这些能力，都会先把草稿摊给你，你确认后才落库；不会静默改你的笔记。
- **导出的文件是明文**，不随空间的加密一起保护。存到哪由你在系统保存对话框里选，点取消就什么都没写。
- **权限是逐条声明、逐项同意的**，不是一次授予全部。插件只能用 manifest 里声明过的能力，后端逐次校验；「声明与实际不符」是明确的违规。
- **当前的插件没有任何联网能力。** 所以静态扫描里看到"看起来在联网"的写法，只会是死代码。
- **没有人工审核，能装不等于可信。** 应用只负责把事实摆出来（来源、权限与理由、签名状态、静态扫描、运行记录），判断权在你。
- **两个主题插件是零代码的**：只有一个 `manifest.json`，没有一行可执行的代码，信任成本和装一个主题一样；启用即生效、停用即恢复，不写入任何配置文件。

### 11.1 形状（为什么是"前端取回来 ＋ Rust 落盘"）
```text
⛔ `src-tauri/src/lib.rs` 是**别人的写域**（本轮不许碰）⇒ 不能新增 Tauri 命令
⭐ 而落盘那条链**仓里已有**：`abilities::save_ability_pack(pack_id, base64)`
   —— 白名单 ＋ 钉死 sha256 ＋ 体积上限，**全部校验通过之后才写盘**（`abilities.rs:8` fail-closed ✓）
⇒ 前端只做「流式取回 ＋ **自己先核一遍** ＋ 交给那条链」，落点是 `<app_data>/packs/ecdict-en-zh/…bin`
   —— 正是**用户的既有数据目录**（⛔ 不入库 ✓），也正是 `dictionary.rs` 的第 2 顺位读点 ✓
```
两道 sha256 **不是重复劳动**：前端那次决定"**要不要落盘**"（危险方向：不匹配就⛔ 根本不调落盘）；
Rust 那次决定"**落盘的字节算不算数**"（⛔ 不信任 webview，`abilities.rs:4` 逐字）。

### 11.2 三条判据（**先红后绿**，原文逐字）
**a) sha256 不匹配 ⇒ 必须拒绝（危险方向优先）**
```text
【先红】$ npx vitest run src/lib/dictionary/download.test.ts
  × 清单里的 sha 与下载内容不符 ⇒ refused，且**一个字节都不落盘**
  AssertionError: sha 不匹配必须拒绝，实际：{"kind":"saved","bytes":22,"sha256":"967fcd10…","saved":{…}}
  expected 'saved' to be 'refused'
  Test Files  1 failed (1) ｜ Tests  1 failed | 10 passed (11)

【后绿】在"落盘之前"加 `if (gotSha256 !== expectedSha256) return { kind: "refused", … }`
  Test Files  1 passed (1) ｜ Tests  11 passed (11)
```
⚠️ 那次红读数是**真的危险方向**：指纹不符的包**被写进了目录**（`kind:"saved"` 且 `savePack` 被调用）。

**b) 下载成功（夹具）⇒ 可用 ＋ 查询能命中**
```text
前端：夹具 22 字节 ⇒ saved；落盘收到的 base64 解出来与下载字节**逐字一致**；
      进度读数：downloading（received 单调不减、末次 100%）→ verifying → saving
      （服务端不给 Content-Length ⇒ percent 如实为 null，⛔ 不猜一个百分比）
Rust：$ powershell -File _tmp\scratch\lookup2-lib-test.ps1 -Filter "dictionary::"
      test a_verified_pack_at_the_pack_path_is_queryable ... ok
      test result: ok. 17 passed; 0 failed; 0 ignored; 0 measured; 872 filtered out
```
（那条 Rust 判据走**能力包落点形状**：`pack_path` → `resolve_db_path` → `pack_check` 通过 → `lookup_at("apple")` 命中"苹果"；指纹错/截断 ⇒ 闸门关。）

**c) 反向：没下载 ⇒ ⛔ 不许假装**
```text
$ npx vitest run src/lib/dictionary/download.test.ts
  ✓ resolvePackUrl() 现在返回 null（真地址＝❌未做），且入口给的是**可读的失败**
  ✓ 注入夹具地址后同一条入口能跑通（＝判据与接口已就绪，只是真地址没有）
Rust 侧同一条（早就红过绿的）：`status_says_not_ready_instead_of_pretending` / `missing_file_is_unavailable_not_a_miss`
```

### 11.3 ❌ 没做的（如实）
1. ⛔ **真地址＝未做**：pack 还没托管到任何稳定地址 ⇒ `download.ts` 里 `ECDICT_PACK_URL = ""`，
   于是 `resolvePackUrl()` 返回 `null`、界面给"还没有托管地址（❌ 真地址＝未做）"。**托管后只改那一行**。
2. ⚠️ **85.6 MiB 过 base64-IPC 的风险仍在**（本轮**未实测**：需要起 app，本轮禁止）。本机实测的两个数：
   ```text
   pack 原始 = 89,735,168 字节；其 base64 = **119,646,892 字符**（Node 里编码耗时 65 ms，⚠️ 非 webview/IPC 读数）
   gzip(9)   = 39,126,809 字节（**2.29×**）；其 base64 = 52,169,080 字符
   ```
   ⇒ 建议（**待拍**）：托管**压缩过**的那份（传输 −56%），或在 Rust 侧下载（同一份白名单＋sha256＋fail-closed，
   先写 `.part` 再改名）。⛔ 无论哪条路：**下载路径里绝不许内置任何 token** ✗（令牌只属开发侧脚本）。

### 11.4 ⑤ `scripts/dictionary-bench.mjs` 现在的定位（保持可复跑）
它量的是**数据层**：`--db <pack>` ⇒ ① 命中率 ② 查询耗时 ③ 未收录怎么呈现（三个读数一条命令）。
⛔ 它**不**量下载链路（那由 `download.test.ts` 的 a/b/c 与 `cargo test` 量），⛔ 也**不**量界面文案
（那是 `lookup.test.ts`）。**三层各管一段**，谁都不许把"跳过/未跑"报成"通过"。

### 11.5 ⭐ 2026-10-10 追加：**Rust 侧下载**（权威实现；`dictionary.rs`）

**为什么换执行者**：86 MiB 过 `save_ability_pack(pack_id, base64)` 那条 IPC 链**结构上**不成立
（`abilities.rs` 文件头逐字：那条链的设计目标是 3.8 MB 级的 PDFium；本 pack base64 = 119,646,892 字符）。
⇒ 语义**逐条不变**，只把"取回来"搬到 Rust：白名单（pin 从 `abilities.rs` **单一来源**取）＋钉死 sha256
＋体积（＝pin）＋**先写 `.part` 再改名**＋校验不过 **`remove_file` 且不 rename**（⛔ 磁盘上不留半个字节）。

**形状**（`dictionary.rs`）：
```text
default_pack_url()      = MIRROR_CONTENTS_API ＋ "mirror/ecdict/ecdict-en-zh.bin" ＋ "?ref=main"
                          （⭐ 与 `AbilitiesPane` 清单里那条 path / API 常量**逐字同形**，判据 `default_pack_url_matches_the_manifest_path`）
install_pack_from_reader(reader, expected_bytes, expected_sha, part, dest, total_hint, on_progress)   ← **纯逻辑**，判据注 `Cursor` 进来
dictionary_install_pack(app, url)  ← Tauri 命令：reqwest 取回（contents API 的 base64 JSON 与普通二进制**两条形状都认**）
                                      ＋ 进度事件 `dictionary-pack-progress` {received,total}
落点 <app_data>/packs/ecdict-en-zh/ecdict-en-zh.bin（＝`dictionary.rs` 第 2 顺位读点 ✓）
```

**判据（先红后绿，原文）**
```text
【先红】把 sha256 比对那一条**摘掉**（模拟"未实现"）：
$ powershell -File _tmp\scratch\lookup2-lib-test.ps1 -Filter "dictionary::tests::install_"

thread '…' panicked at src\dictionary.rs:1190:10:
called `Result::unwrap_err()` on an `Ok` value: PackInstallReport { path: "…\ecdict-en-zh.bin", bytes: 12288, sha256: "73b1285a…", source: "" }
test result: FAILED. 2 passed; 1 failed; 0 ignored; 0 measured; 890 filtered out
```
⇒ 那次红正是**危险方向**：指纹不符的那份**被 rename 成了正式文件**（`Ok` ＋ 落点路径）。
```text
【后绿】把比对放回（删 `.part` ＋ 拒绝）：
$ powershell -File _tmp\scratch\lookup2-lib-test.ps1 -Filter "dictionary::"
test result: ok. 21 passed; 0 failed; 0 ignored; 0 measured; 872 filtered out
  其中：install_refuses_a_sha256_mismatch_and_leaves_no_bytes（拒绝＋两处都不留）
        install_refuses_truncation_and_overrun_and_leaves_no_bytes（半包/超长/没钉 pin ⇒ 都拒）
        install_reports_total_as_none_when_the_server_does_not_say（无 Content-Length ⇒ total 如实 None）
```

**gzip 版（备好给提包用，实测）**
```text
原始 pack : 89,735,168 字节  sha256 = 5dc10a51f33a0a61d4cb4f368a220a50f8bccb8c2ff3488fdadd5eaaaea2bb31
```

⚠️ ⛔ **Rust 侧直接下 gzip ＋ 解压**需要 `flate2`：它**已在 `Cargo.lock`**（1.1.10，随 `zip` 进来），
但要用它必须往 `src-tauri/Cargo.toml` **加一行直接依赖** ⇒ 那个文件**不在本轮写域**（改它要 Lead 批）。
⇒ 本轮的实现按**未压缩的 `.bin`**（＝清单里现有的 `bytes`/`sha256`）走；要改 gzip 路线 ⇒ 加那一行 ＋ 一条
"解压后逐字节一致"的判据（上面 gzip 那三个读数已经先量好了）。

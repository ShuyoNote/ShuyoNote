# 「Wiki 织网增强」方案（M19）

> 目标版本：v1.60.x（提议）。关联：[路线图 M19 里程碑](../roadmap.md)、[系统架构](../architecture.md)。
> 状态：**规划（建议）**。把「双链」从"能链接"做深为"真织网"，对标 Obsidian 双链 / wiki。

## 1. 背景与目标

- ShuyoNote 已有页面双链 `[[标题]]`、块引用 `((块ID))`、块反链、关系图——"能链接"。
- 但离"织网"还差：**发现**（哪些地方该链接却没链）、**精确**（链到具体块 / 显示别名）、**引导**（输入时智能提示）。
- 目标：让使用者"记录=织网"，链接关系自动生长。

## 2. 目标体验

### M19.1 未链接提及（Unlinked Mentions）
- 扫描当前页正文里出现的**其它页面标题**，若该处是纯文本**未打 `[[ ]]`**，在页面底部「反链/提及」区提示「检测到可能是链接：`《标题》`」。
- 点击「改为链接」→ 把该处文本替换为 `[[标题]]`；可「忽略」。

### M19.2 双向链接别名 + 精确块链
- `[[标题|别名]]`：显示"别名"，链接仍指向目标页（解析时按别名匹配）。
- `[[页面#块]]` / `[[页面#块id]]`：直接链到目标页的**具体块**（复用现有稳定 `blockId`），跳转时定位到该块（复用 `focusBlockId` + `data-block-id` 滚动）。

### M19.3 链接建议增强
- 输入 `[[` 时，候选按「当前页上下文相关 / 最近编辑 / 标题匹配」排序。
- 粘贴一个已有页面标题时，自动识别并建议转为 `[[标题]]`。

## 3. 技术要点

- **匹配**：`search`（FTS/标题）返回全库标题；「未链接提及」用 `content_text` 扫描标题子串（CJK 用现成 `tokenize`），排除已 `[[ ]]` 包裹处。
- **转链**：在 Lexical 里把对应 `TextNode` 替换为 `LinkNode`（`@lexical/link`）或自定义双链节点；别名经 `label`/`title` 字段承载。
- **块链**：`[[页面#块id]]` → 目标 `blockId` → `useEditorStore.setFocusBlockId(id)` 触发滚动高亮（复用现有 `BlockIdPlugin`）。
- **解析**：`parser` 扩展 `[[...]]` 语法（与现有 `markdownTransformers`/块引用解析对齐），`resolve` 到 page/block。

# M24 PDF 批注 · 手动验收清单（阶段 1，Web / 桌面）

> 目的：在真实浏览器 / 桌面里把「阅读 + 批注 + 批注即块」整体走一遍。**渲染与批注依赖 canvas + pdf.js，必须真机验证**；无头环境只保证自动化门禁。前置：导入一个 `.pdf` 到文件夹做测试（或用真实论文 / 扫描件各一）。

## 0. 自动化门禁（应全绿）
- [ ] `npx tsc --noEmit`
- [ ] `node scripts/smoke-web.mjs`（**283 passed, 0 failed**）
- [ ] `pnpm build`
- [ ] `cargo test --lib`（**32 passed**）

启动：桌面 `pnpm tauri dev`(1420) 或 Web `pnpm dev:web`(5173)，改动后**硬刷新**（Ctrl+Shift+R）。

## A. 入口
- [ ] 文件夹视图有一个 `.pdf` → 点开预览（iframe 显示 PDF）。
- [ ] 预览头出现「**阅读并批注**」按钮。
- [ ] 点击 → 打开**阅读器**（模态，标题 = PDF 名）。
- [ ] 取字节失败 → toast「无法读取 PDF…」，界面不崩。

## B. 渲染
- [ ] 第一页渲染出来，工具条可见（选择 / 高亮 / 画笔 / 便签）。
- [ ] 页脚「第 X / N 页」正确。
- [ ] 顶部显示「**有文本层 / 无文本层（矩形/画笔/便签更稳）**」状态。
- [ ] 翻页 `‹ ›` 正确，首/末页按钮禁用。
- [ ] 缩放 50%–300%：页面清晰、**批注不漂移**（缩放后仍锚定原页坐标）。

## C. 批注
- [ ] **高亮**：拖框 → 半透明黄色高亮。
- [ ] **画笔**：拖动 → 蓝色折线。
- [ ] **便签**：点击 → 输入内容 → 黄色便签标记，悬停显示文本。
- [ ] **选择**：点某批注 → 操作条出现「摘录成块 / (便签)编辑 / 复制引用 / 删除」。
- [ ] **删除** → 批注消失，重开仍在（已删）。
- [ ] **(便签)编辑** → 改文本，保存生效。
- [ ] **复制引用** → 剪贴板为 `pdf://<attachmentId>#<page>`。
- [ ] 拿一个**无文本层/扫描件**：顶部提示走「无文本层」降级分支。

## D. 持久化
- [ ] 在几页加若干批注 → 关阅读器 → 重新打开同一 PDF：各页批注都在（翻到对应页核对）。
- [ ] 切空间 / 重启后仍在（本地 `pdf_annotations`，内容寻址）。

## E. 批注即块（摘录成块）
- [ ] 选中批注 →「**摘录成块**」：
  - [ ] 若有当前打开页 → 段落**追加进当前页**（正文含 `pdf://` 回链），阅读器关闭并落到该页。
  - [ ] 若无当前页 → 新建「**摘录**」页，含回链。
- [ ] 全局搜索搜摘录文本 → **能搜到**（进 `content_text`）。
- [ ] 回链解析：`parsePdfRef("pdf://att#2")` → `{attachmentId, pageIndex}`（smoke 已断言）；阅读器 `openPdf(id, name, pageIndex)` 可跳到对应页。

## F. 异常 / 边界
- [ ] 无 PDF / 取字节失败 → toast，不崩。
- [ ] 超大 PDF → 按需渲染，连续翻页不卡死/不崩。
- [ ] 深浅主题下阅读器、工具条、批注可读。
- [ ] 点背景 / Esc → 关闭阅读器。

## G. 已知诚实标注
- 桌面 **native 引擎**（pdfium/mupdf）未做；桌面 webview 用 pdf.js 兜底，性能优化项。
- 阅读器浏览器行为未在无头环境验证，以本清单为准；若渲染/坐标/交互有偏差，反馈修。

## 0. 一句话

```text
A1 G0 只做一件事：**两条血统相容的编辑历史**，在**默认关的开关**下，允许块级自动合并；
血统不相容仍**拒绝**（保留 U4 安全闸）；⛔ 不做“无提示强行合并”，⛔ 不改库结构。
```

## 2. G0 的边界（先划死）

```text
✅ 做：
  · 同血统（lineagesRelated=true）且两边都有可合并 CRDT 状态 ⇒ 尝试块级合并；
  · 合并成功 ⇒ 落库、写投影、留痕（哪页、哪些块、耗时）；
  · 合并失败/摘要不一致 ⇒ **保留本地**、记录失败原因、提示“未自动合并”，⛔ 不丢任何一版；
  · 血统不相容 ⇒ 原 U4 拒绝话术，⛔ 不进合并路径。

⛔ 不做（G0 明确排除）：
  · 无 CRDT 状态的旧页（仍走页级最后写入 + 人工裁决）；
  · 加密空间（先不动；G2 再评估）；
  · 附件/属性/数据库页（只做普通笔记页）；
  · 同块同位置冲突的“自动挑赢家”（留 G1+，先报告不静默）。
```

## 3. 开关与回滚

```text
G0 实现口径（2026-11-22 落地时订正）：
  · 同血统合并**今天已经在跑**；G0 先把它变成**显式 kill switch**，默认**开**，
    设 `VITE_CRDT_A1=0`（或 false/off）才关 —— 关掉 = 回滚到“不合并、保本机”。
  · 原设计写“默认关”，但那样会把已经在跑的合并**静默关掉**；改成“默认开 + 显式关”更安全。
  · 运行时空间设置 `crdt.autoMerge` 留到 G1（G0 只做构建期开关）。

回滚：
  · 关开关 ⇒ 立刻回到今天的行为（页级最后写入 + U4 拒绝）；
  · 不迁数据、不删 `page_crdt`、不重打 tag；
  · 合并失败记录保留，供复盘（不自动清）。
```

## 4. 数据流（G0）

```text
远端页载荷
  └─ 有 crdt_state？
       ├─ 否 ⇒ 现有路径（U4 裁决）
       └─ 是 ⇒ 血统相容？
            ├─ 否 ⇒ U4 拒绝（话术不变）
            └─ 是 ⇒ A1 开关开？
                 ├─ 否 ⇒ 现有路径（⛔ 行为不变）
                 └─ 是 ⇒ mergeRemotePageState（块级）
                      ├─ 成功且投影摘要一致 ⇒ 落库 + 留痕 `a1_merge`
                      └─ 异常/摘要不一致 ⇒ 保本地 + 留痕 `a1_merge_failed` + 提示
```

## 5. 判据（G0 必须先立）

```text
纯函数/单元：
  ① lineagesRelated 同血统 ⇒ true；不相容 ⇒ false（已有，补 A1 用例）
  ② 合并幂等：同一远端状态应用两次 ⇒ 第二次无变化（摘要相同）
  ③ 收敛：A+B 与 B+A 合并后的块级摘要一致（⛔ 不比对 UI 文本）
  ④ 拒绝：血统不相容 ⇒ 不调用合并，返回 U4 话术
  ⑤ 失败保护：合并抛错/摘要不一致 ⇒ 本地页内容、附件、归档逐字节不变
真机：
  ⑥ 两台设备各改**不同块** ⇒ 自动合并，两边最终一致
  ⑦ 两台设备改**同一块同位置** ⇒ G0 **不自动解决**，报告冲突、保双方
  ⑧ 关闭开关重放 ⑥ ⇒ 回到页级裁决（证明开关有效）
```

## 8. 风险与止损

| 风险 | 止损 |
|---|---|
| 合并后少块/丢附件 | 摘要+附件清单比对；不一致 ⇒ 保本地、停止灰度 |
| 投影写回与 CRDT 状态不一致 | 投影摘要不一致 ⇒ 记失败、不落库 |
| 同块冲突被“自动挑赢家” | G0 明确不做；只报告 |
| 加密空间行为变化 | G0 不碰加密空间 |
| 旧页无 CRDT 被误合并 | 只处理“有 crdt_state”的页 |

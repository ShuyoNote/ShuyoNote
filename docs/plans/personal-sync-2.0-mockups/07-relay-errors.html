ShuyoNote 个人版同步 2.0·效果图 07 / 跨网失败三态：只收回跨网，局域网照常

跨网出问题时，本机不受影响

私有中继的失败要能一眼看出是哪一种，并给出下一步；无论哪种，本地读写与局域网同步都不降级。
设置 / 同步 / 跨网（私有中继）局域网：已连接 · 2 台设备
① 证书问题
TLS 握手失败：证书过期/不匹配
中继的证书到期或域名对不上 ⇒ 跨网暂停；局域网与本地照常。
下一步：部署人续期证书（certbot）或修 SAN；relay 会按小时重读证书，无需重启。
重新检测查看部署文档
② 许可证到期
到期只收回“跨网”
订阅到期 ⇒ 跨网连接被拒（理由可读）；本地读写/搜索/编辑/局域网同步全部照常。到期≠软件不能用。
下一步：续期许可证后自动恢复。
续期入口了解许可
③ 端口/配置未通
8881/8882 不可达
HTTPS 8881 或 QUIC 8882/udp 未放行 / 证书链不完整 ⇒ 测试连接失败。
下一步：放行端口、确认 TLS 证书链、再点「重新检测」。
重新检测复制诊断
共同口径：跨网失败不降级局域网；中继不可达时只显示“跨网暂不可用”，本机与同 Wi-Fi 同步继续。
读数如实：状态页里证书剩余天数在未解析前显示「—」（⛔ 不编数字）；relay selfcheck 四项未做前不写“已通过”。

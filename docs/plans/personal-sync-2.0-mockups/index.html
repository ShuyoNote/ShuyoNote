个人版同步 2.0 · 效果图

原则：没有中继服务器，局域网同步与 MCP 必须完整可用；中继只作为付费可选的私有部署。以下 4 张图对应 P1/P2/P3 的关键界面。
01 · 默认局域网：打开即用
不需要服务器；按空间显示状态；全部空间同步；连接体检入口；私有中继收在高级里。
02 · 连接体检：把“为什么不同步”说清楚
接口/发现端口/同步窗口/对端可达/配对秘密/房间/最近一轮；手动 IP 兜底；复制脱敏诊断包。
03 · 私有中继：付费可选，用户自己部署
官方安装包 + 许可证；三步接入；LAN 优先、中继兜底；中继故障不影响局域网；合规责任提示。
04 · 后台与 MCP：同步独立，MCP 本地优先
关窗继续同步、托盘；MCP 不依赖中继；无 UI 危险写默认拒绝；后台 MCP 默认关。

需要拍板的 6 件事（白话）

DEC-1 传输A 先 HTTP + mDNS/手动/并发，P3 再 QUIC（推荐）｜B 直接 QUIC 直连
DEC-2 后台A 先 App 托盘常驻（推荐）｜B 直接独立 daemon
DEC-3 CRDTA P3 双写/灰度迁移普通笔记页（推荐）｜B 暂不迁，维持页级
DEC-4 私有中继A 官方安装包 + 许可证，用户自部署（推荐）｜B 我们运营公共中继（不建议）｜C 不做跨网
DEC-5 MCPA V1 留在 App（推荐）｜B 托盘常驻可用｜C P3 迁 daemon
DEC-6 中继启用A 默认不启用、配置后才用（推荐）｜B 订阅用户默认启用

「—」不是 0，也不是“已同步”；每个「—」点进去都能看到具体原因。
点进「—」：为什么读不到
1
设备离线 / 不可达
没有心跳也没有公告 ⇒ 不知道它到哪一轮（⛔ 不猜）。
2
该空间没开同步
对端这台设备没有为这个空间开启同步 ⇒ 它没有水位。
3
本机没有这个空间
对端有、本机没有 ⇒ 这一列对你不适用（不是“差很多”）。
判据：读不到显示「—」＋原因；⛔ 不显示 0 / “已同步”；原因必须来自真实读数。

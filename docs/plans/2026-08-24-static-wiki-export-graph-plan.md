# 「静态 wiki 导出 + 关系图探索」方案（M21）

> 目标版本：v1.60.x（提议）。关联：[路线图 M21 里程碑](../roadmap.md)、[Markdown 导出](../architecture.md)。
> 状态：**规划（建议）**。「本地优先 + wiki」的终局：把你的空间导成可独立浏览的 wiki 网站，并把关系图从"能看"升级为"能探索"。

## 1. 背景与目标

- 现有[导出](./2026-08-15-local-first-note-app-plan.md)支持：单页 Markdown/HTML/PDF、整库备份 zip、工作空间 Markdown 批量导出。
- 缺：把整个空间导出成**可独立浏览、双链可跳转**的静态 HTML wiki 站点。
- 关系图已存在（页面/块级），但偏"展示"；希望按标签/属性着色分组、关键词高亮、聚类，便于"探索"。

## 2. 目标体验

### M21.1 静态 wiki 导出
- 命令面板「导出当前空间为 wiki」：把当前空间的所有页面导出为**静态 HTML 站点**——
  - 每页一个 `.html`，正文 + `[[标题]]` 双链渲染为可点击链接、`/*块*/` 锚点定位；
  - 产出「反向链接/提及」区、标签、一个索引页/关系图页；
  - 生成 `index.html`（页面树入口），可整体投喂到任意静态托管（如 GitHub Pages / 本地 file://）。
  - 复用离线 `createEditor`（同 Markdown 批量导出）生成 HTML；附件以内容寻址导出到 `assets/`。

### M21.2 关系图探索增强
- 关系图节点按**标签/属性**着色分组；关键词高亮；聚类（同类聚拢）。
- 点击节点/边即跳转对应页面/块；支持局部缩放与锁定。

## 3. 技术要点

- **导出器**：复用 `src/lib/exportMarkdown.ts` / `print.ts` 的 HTML 生成；`[[ ]]`/`((块))` 解析为 `<a href>`；附件哈希写到 `assets/<hash>`。
- **双链解析**：导出时从库构建 page→title→id 映射 + `blocks` 块索引，生成链接/锚点。
- **图探索**：`get_graph` 数据已有；前端按 `attr`/`tags` 分组着色，用力导向布局 + 聚类（SVG/Canvas）。

## 4. 验收 / 里程碑

- [ ] 导出为可浏览的静态 HTML wiki（页面 + 双链 + 反链 + 标签 + 索引页 + 附件 assets）
- [ ] 导出产物可离线打开/静态托管
- [ ] 关系图按标签/属性着色分组、关键词高亮、点击跳转
- [ ] `scripts/smoke-web.mjs` 新增断言且原断言无回归；`tsc`/`vite build`/`cargo check` 通过

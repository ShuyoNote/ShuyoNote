## 0. 一句话

```text
G1 只对**明文空间、且显式打开 `crdt.autoMerge` 的空间**启用块级自动合并；
默认关；任何一天影子扫描出现少块/内容级不一致/异常 ⇒ 停止并回滚。
⛔ 本期不覆盖加密空间、附件/属性/数据库页、同块同位置自动挑赢家。
```

## 1. 启用前置（缺一不启）

```text
① 影子窗口：2026-11-23 起连续 **7 个有效日**（明文空间口径）；
   每天“少块 0 / 内容级不一致 0 / 异常 0”；加密空间记“排除”，不算覆盖。
② 安全闸在岗：状态投影 ≠ 内容列 ⇒ 拒绝合并、保本机（已实现，staleState）。
③ 写路径收口：PDF/guide/AI/历史恢复/ConflictBanner 已维护；通用 save_page 有 opt-in；
   未收口路径不得在灰度空间出现（先核）。
④ owner 明确拍板“开哪个空间、开几天”。
```

## 2. 开关（G1 新增，默认关）

```text
空间级：`crdt.autoMerge`（默认 false；G1 只允许手动给一个空间置 true）
构建级：`VITE_CRDT_A1` 仍是总开关（显式 0/false/off ⇒ 全关）
运行时：两者都开才走合并；否则走“保本机 + 提示”（现有 disabled/staleState 路径）
⛔ 不新增数据库表；设置存空间 KV（与现有空间设置同层）。

⚠️ **前置代码差距（2026-11-24 如实记）**：G0 的 kill switch **默认是开**的
（`a1AutoMergeEnabledFrom` 只认显式 0/false/off 为关）⇒ 今天同血统页**已经在自动合并**。
G1 要的“默认关 + 按空间开”**尚未实现**；在实现前，⛔ 不能把当前状态称作“G1 灰度”。
实现时需把默认值/空间门加进去，并更新既有 pageBinding 判据（它们默认期待合并）。
```

## 3. 批次（个人版，空间少）

| 批次 | 范围 | 观察期 | 通过判据 |
|---|---|---|---|
| G1-a | 自用测试空间 1 个 | 3 天 | 每日影子 0 危险；无“块变两份/丢块” |
| G1-b | 1 个真实明文空间 | 7 天 | 同上 + 用户无“内容被覆盖”报告 |
| G1-c | 其余明文空间（逐个开） | 每空间 7 天 | 同上；任一红 ⇒ 单空间回滚并停下 |

## 4. 每日判据（与窗口同一口径）

```text
跑：A1_SHADOW_SCAN=1 A1_ALLOW_ENCRYPTED_EXCLUDED=1（日志落 _tmp/logs/a1-shadow/）
看：
  · merged_fewer_blocks > 0 ⇒ **立即停灰度 + 回滚空间开关**
  · projection_mismatch > 0 ⇒ 先归因（元数据/真差异），未归因前不前进
  · exception > 0 ⇒ 停，保留日志与现场
  · lineage_incompatible > 0 是正常拒绝，不算失败
人工：出现“内容被覆盖/块重复”任一报告 ⇒ 停
```

## 5. 回滚

```text
1) 空间设置 `crdt.autoMerge=false`（或总开关 VITE_CRDT_A1=0）；
2) 不迁数据、不删 page_crdt、不重打 tag；
3) 已合并的页保留；用版本历史/另存为新页人工恢复；
4) 回滚后重跑一次影子扫描，确认“少块/内容级不一致”归零；
5) 事故记录写进交接单，⛔ 不补造读数。
```

## 6. 明确不做（G1 边界）

```text
· 加密空间（G0/G1 都不覆盖）
· 附件/属性/数据库页（只做普通笔记页）
· 同块同位置冲突的自动挑赢家（只报告，人工裁决）
· 无 CRDT 状态的旧页（继续页级最后写入）
```

## 7. 拍板时需要的输入

```text
· 7 天影子报告汇总（有效日、每天少块/内容级不一致/异常）
· U3/U4 真机读数（至少 U4 块级冲突）
· 目标空间 id/名称（只开一个）
· 观察期长度（默认 3 天自用 / 7 天真实空间）
```

| 元素 | 现在应该有 | 现在**确实没有**（⛔ 别当成 bug 报 ✗） |
|---|---|---|
| 顶部黄条「本机有 N 个空间没开加密…」 | ⭐ **N＞0 才出现** ✓（N=0 ⇒ 整条不渲染 ✓） | ⛔ 「去开加密 ›」那颗**动作不渲染** ✗（目的地是桌面专属，见 §5） |

| 三颗胶囊（已配对／要重配／附近） | ⭐ 有设备时才出现 ✓；**当前那颗实心蓝** ✓；点另一颗**真的过滤** ✓ | ⚠️ 该档为空时**灰掉不可选** ✓（⛔ 不是"能点进去是空"✗） |

2. **dev 壳里「附近设备」列表为空** ✓：这是"当时没别的设备在线" ✓，⛔ 不是"做坏了" ✗。

## 5. ⭐ 明确**还没做**的（⛔ 别报成 bug ✗）

| 还没做 | 为什么 | 谁办 |
|---|---|---|
| 手机端「**编辑旧笔记**」入口 | `MobileRead` 只读；A 方案（新组件＋一处入口）已排给 windows，尚未合入 | windows／下一轮 |
| 设备卡「**立即同步**」 | 按**空间**同步，挂到单台设备会指错 | 需要按空间设计 |
| 逐台**解除配对** | 那侧只有 `device_id`＋时间、没有名字 ⇒ 显示会说谎 | 下一轮 |
| 「**去开加密 ›**」 | 目的地「空间隐私」自己写着「**要在桌面端操作**」✗ ⇒ 渲染它就是假按钮 ✗ | 桌面侧／owner |
| 「**高级（已自动填好）›**」 | 面板在桌面 `SyncPanel` 里 ✗ ⇒ 移动端到不了 ✗ | — |
| 空间包**大空间真机** | 代码/单测在；大空间/系统保存对话框未真机验 | owner 真机 |

# 「文件夹 = 网盘」实现方案

> 目标：把文件夹从「只是页面层级容器」升级为**同时承载文件的网盘**——一个项目文件夹 = 文档 + 素材（PDF/图片/表格/压缩包）在一个地方。差异化是 ShuyoNote 的本地优先 + 内容寻址去重 + 自建同步 +（规划中）端到端加密，形成「私有、去重、无限速、可加密的网盘」，而非公网网盘的替代。

## 1. 背景与竞品对照

| 竞品 | 文件夹/文件能力 | 关键点 |
|------|-----------------|--------|
| FlowUs / Wolai | 文件夹 = 文件库 | 文件夹内可直接上传/预览文件，文件预览内嵌 |
| 有道云笔记 | 文件夹装笔记+附件 | 笔记/文件混排在一个文件夹 |
| Quark / 百度网盘 | 纯云盘 | 有分享/配额/转存生态，但非笔记 |
| ShuyoNote 现状 | 文件夹有「半网盘」 | FileManagerView 已有上传/list/移除，但缺在线预览/拖拽/搜索/下载/统计 |

**结论**：ShuyoNote 已有文件库种子（文件夹上传、流式、内容寻址去重），缺的是**把它扶正的网盘 UX**。本方案聚焦核心网盘交互（上传/预览/搜索/下载/统计/跨夹移动），**不做**分享/配额/转存等公网网盘生态（见[设计哲学](design-philosophy.md)边界）。

## 2. 现状盘点（代码已核实）

| 位置 | 现状 | 缺口 |
|------|------|------|
| `FileManagerView.tsx` | 文件夹 → 文件表格（名/类型/大小/修改时间），新建/上传/移除，批量流式上传，面包屑 | 无在线预览 / 无搜索 / 无显式下载 / 无每夹统计 |
| `TreeFiles`（PageTree） | 侧栏树文件夹下显示文件（图标+名） | 无文件搜索 / 无预览 |
| `attachments.rs` | `save_image/attachment_path/list_attachment_hashes/read/write_attachment_bytes/import_attachment_files/list_page_attachments/remove_attachment`——内容寻址（hash）存取 | 需「预览 URL/数据」「下载到目标路径」 |
| 文件归属 | 文件 = `attachments.page_id = 文件夹.id` | 跨夹移动需改 `page_id` |

## 3. 核心概念

- **文件夹 = 文件库根**：文件夹同时是页面树节点与文件库；文件以 `page_id = 文件夹.id` 归属该夹。
- **文件是一等公民**：文件本身存在于文件夹（可搜索/预览/下载/移动），页面可通过「引用」关联（页面附件模型并存）。
- **本地优先 + 内容寻址**：文件按内容哈希存储、跨夹去重；上传/下载流式；可选自建同步；M2 加密后服务器不可读。
- **网盘 UX（本期范围）**：拖拽上传、在线预览、文件名搜索、另存为、每夹大小/数量统计、跨夹移动。**不做**分享/配额/转存。

## 4. 数据模型（无新表）

- 复用现有 `attachments` 表：`id, page_id(=文件夹), name, hash, mime, size, ...`。
- 跨夹移动文件 = 更新 `attachments.page_id`（新文件夹 id）。
- 每夹统计 = `SELECT COUNT(*), COALESCE(SUM(size),0) FROM attachments WHERE page_id = ?1`。

## 5. 前端设计（FileManagerView 增强）

### 5.1 拖拽上传
- 把 OS 文件拖入文件夹视图 → `importAttachmentFiles(folderId, paths)`（现成流式接口），显示进度。

### 5.2 在线预览
- 点文件行 → 预览面板/模态：按 `mime` 分流
  - 图片 → `<img>`；视频 → `<video controls>`；音频 → `<audio controls>`；PDF → iframe/embed；文本 → `<pre>`；其他 → 提示用系统打开。
- 数据：`read_attachment_bytes(hash)` 取字节 → Blob URL（或 `attachment_path` 提供本地路径）。本地优先建议用后端提供的本地路径直接预览（`attachment_path` + `convertFileSrc`），避免整块进内存；超大文件仍流式/分块。

### 5.3 搜索文件
- 文件表格上方加搜索框，按文件名过滤（前端即时过滤）。

### 5.4 另存为 / 下载
- 每行「下载」→ `save` 对话框 → 从 `read_attachment_bytes`（或路径复制）写到目标路径。

### 5.5 每夹统计
- 文件夹头部显示「N 个文件 · 共 X MB」；按文件大小求和。

### 5.6 跨夹移动文件
- 文件行「移动到」→ 选目标文件夹（复用面包屑/页面树选夹）→ 改 `page_id`。

## 6. 后端命令（新增/改造）

| 命令 | 说明 |
|------|------|
| `list_folder_files(folder_id)` | 列出文件夹内文件（已有 `list_page_attachments`，改名为 `list_folder_files` 或复用） |
| `move_attachment(attachment_id, new_page_id)` | 跨夹移动（`UPDATE attachments SET page_id=?`） |
| `download_attachment(attachment_id, dest_path)` | 从内容寻址读字节写到目标路径（或用路径复制） |
| `folder_stats(folder_id)` | `{count, total_bytes}` |
| `preview_attachment(attachment_id)` | 返回本地路径 / blob URL（复用 `attachment_path` + `convertFileSrc`） |

> 复用现有 `attachments.rs` 的流式/内容寻址设施；预览走本地路径方案（本地优先），避免整块进内存。

## 7. 实施顺序（里程碑）

- **M12.1（核心网盘 UX）**：文件表格加搜索 + 每夹统计 + **在线预览**（图片/视频/音频/PDF/文本）+ 显式**下载**。验收：文件夹里点文件能预览、能搜索、能批量看大小。
- **M12.2（拖拽 + 移动）**：拖拽 OS 文件进文件夹上传 + 文件跨夹移动。验收：拖入即上传为文件库文件；文件可在文件夹间移动。
- **M12.3（深化，可选）**：文件类型/标签元信息、文件引用到页面（页面内嵌引用某文件库文件）、文件版本；跨夹统计/批量管理。

## 8. 测试与验收标准

- [ ] 在文件夹上传文件后，文件出现在文件库，侧栏树同步显示。
- [ ] 点击文件可**在线预览**（图片内嵌、视频/音频播放、PDF、文本），超大文件不整块进内存（走本地路径）。
- [ ] 文件搜索按名过滤正确。
- [ ] 每夹显示文件数 + 总大小。
- [ ] 文件可「另存为」到本地路径。
- [ ] 文件可跨文件夹移动，移动后属新夹。
- [ ] 内容寻址去重：同一文件在不同夹不重复占空间。
- [ ] 同步 / 版本历史 / 回收站不受影响（文件随页面走；附件内容寻址）。

## 9. 风险与取舍

- **预览方式**：本地优先建议用后端 `attachment_path` + `convertFileSrc` 直接预览本地文件，避免全量读进内存（超大文件仍分块/流式）。WebView 对外部本地路径的预览需 `convertFileSrc`（Tauri asset 协议）。
- **别滑向公网网盘**：不做分享/配额/转存/云盘会员——那是另一个产品；聚焦「私有、本地、去重、可加密」。
- **拖拽上传的进度**：复用现有 `import_attachment_files` 流式进度事件。
- **跨夹移动的边界**：移动后保证原夹侧栏/文件列表刷新。

## 10. 结论

「文件夹 = 网盘」把 ShuyoNote 从「笔记 + 附件」升级为「**项目空间 = 文档 + 素材**」，配合本地优先 + 内容寻址 +（规划中）端到端加密，形成与公网网盘差异化的「私有网盘」。按 M12.1 → M12.2 → M12.3 收紧推进；分享/配额延后。配套设计取向见[设计哲学](design-philosophy.md)。

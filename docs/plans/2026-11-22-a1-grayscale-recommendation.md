## 2. 建议的批次（默认值继续关，用户无感）

| 批次 | 范围 | 开关 | 观察期 | 进入下一批的判据 |
|---|---|---|---|---|
| **G0 实现** | 合并路径 + 开关 + 回滚 + 埋点；只在 dev/本机 | 隐藏开关（env/localStorage） | 无（开发自测） | 单测/门禁全绿；手工演练回滚成功一次 |
| **G1 自用** | 你自己 + 一个测试空间 | 空间级开关 | **3 天**（建议） | differUnexplained 日计数 = 0；无合错/丢失；p95 不劣化 >2 倍 |
| **G2 单空间** | 1 个真实空间（普通页） | 空间级开关 | 3–5 天 | 同上 + 有回滚演练读数 |
| **G3 默认** | 普通页默认开（随某个正式版本） | 全局开关（可关） | 发版后观察 | 发版说明写清 + 一键回滚路径 |

## 3. 回滚（必须一键，且不迁数据）

```text
· 开关层级：G0 = 本机隐藏开关；G1/G2 = 空间级；G3 = 全局（默认开、可关）
· 回滚动作：关开关 ⇒ 下一轮/下次启动生效；不删数据、不做库迁移
· 回滚演练：G1 开始时真做一次，留下"关→开"的读数（否则"可回滚"只是声明）
```

## 4. 停止条件（任一出现，立即关＋报告）

```text
· 非测试页出现 differUnexplained > 0
· 任何"内容丢失 / 合错 / 页面打不开 / 保存失败"的用户报告或日志
· 合并后出现无法用「留本地/用远端」挽回的状态
· 保存→同步 p95 比基线劣化 >2 倍
```

## 5. 观测指标（都要有来源）

```text
· differUnexplained 日计数（已有：影子历史）
· 冲突数、合并耗时 p50/p95（G0 需新增埋点）
· 回滚次数、保存失败数、合并后打开失败数
· 基线：Phase 0 的"改→可见 p50/p95"（见 §13.12），没有基线不算完成
```

## 1. 要解决的问题（今天已经量到的）

一路是"**我按对端的高水位往前追**"（`since=cursor` 拉增量）。它有一个结构性弱点：
**只能追一条已经存在的水位**。以下三种情况它帮不上忙：

1. **缺口是被"跳过"造成的**（F3 今天量到：被跳过 8 次 / 累计失败 8 台次）——
   某一轮里跳过了谁，那几条就**留在对面**，要等下一轮"恰好没跳过它"才补上；
2. **两条血统分叉后，谁也没法自动收**（U4 的 `KeptLocal`：对端那版进「待取回」等人工裁决）——
   反熵**不能**替用户裁决，但可以让"**到底缺几页/哪些页**"这件事**跨机可见**；
3. **三台以上时，"谁缺谁"只在各机自己的 `[sync-metrics]` 里**，没有一台能看到全局。

⇒ **F2 的目标不是"自动合并"，而是"让缺口跨机可见、可核对、可补齐"**，并且**只补"我确认缺的"**。

## 2. 非目标（⛔ 这一版都不做）

- ⛔ **不做自动裁决**：血统分叉仍然只能由用户在面板三选一（U4 的闸门不动）；
- ⛔ **不跳过授权**：任何"补数据"的请求仍走既有的**卡表**（`mesh_paired_devices`）与空间身份判定；
- ⛔ **不引入后台拉取的新入口**：补数据复用现有 `/mesh/pull`（只多一个参数），不新增端口/服务；
- ⛔ **不改变"谁赢"**：反熵只补"本机根本没有的变更"，⛔ 不参与"同一页谁更新"的判定。

## 3. 机制（两步，都可单独上线）

### 3.1 第一步：**缺口清单**（只读、只提示）

新增一个**只读**端点（同一扇门、同一套鉴权）：`GET /mesh/gaps?space_id=…&device=…`
返回**对端认为"我这台缺哪些 seq 段"**——但注意：**对端不可能知道我的游标**。
所以这一步真正的形状是**反向**的：

```text
我 → 对端：GET /mesh/gaps?space_id=…      （我拿"你的高水位 + 你的 seq 段清单摘要"）
对端 → 我：{"max_seq": 812, "ranges": [[1,120],[121,240],…], "digest": "<对 item 计数与首尾 seq 的摘要>"}
我：拿自己的 cursor 与本地 item 表比 ⇒ 得出「我缺的段」
```

**为什么用"段清单摘要"而不是"逐条 id"**：三条纪律都指向摘要——
① 体量（3 台 × 逐条 id 会把一个轮次撑到 MB 级）；
② 脱敏（段号不含标题/内容；`[sync-metrics]` 今天已经在用 `max_seq`/`gap` 这套口径）；
③ 可复算（`digest` 用"计数 + 首尾 seq"就够判"我们是不是同一份清单"，⛔ 不是内容哈希）。

⚠️ **它只回答"缺不缺"，不负责补**：第 3.2 步才补。

### 3.2 第二步：**定向补齐**（复用现有 pull）

```text
我 → 对端：GET /mesh/pull?space_id=…&since=<缺口段的起点>&limit=…&caps=…  （现有端点，现有鉴权）
```

⇒ **不新增协议**，只把"since 从哪儿开始"改成**由缺口清单算出来**，而不是死用 `cursor`。
这让"跳过造成的缺口"能在**下一轮立刻补**（而不是等它自然对齐）。

## 4. 判据（先写红，再实现）

1. **纯函数**：`gapsOf(myCursor, remoteRanges) -> 段列表`（空/重叠/乱序/坏形状 ⇒ 明确结果，⛔ 不猜）；
2. **摘要比对**：`digestOf(items) == remote.digest` ⇒ "同一份清单"（判据覆盖：数量不同 / 首尾不同 / 空表）；
3. **源级纪律**：补数据那一支**必须**复用 `crate::mesh::round` 的候选与鉴权（判据：`grep` 源码，
   ⛔ 不许在反熵路径里自己开一条"跳过候选人"的连接）；
4. **真机（3 台）**：三台在线 → 制造一次"某轮跳过 A" → 下一轮缺口清单**报出来** → 定向补齐后
   `gap` 归零，且 `[sync-metrics]` 的 `fetched/applied` 与之对得上。

对端是旧版时一律**退回现状**（⛔ 不许出现"看起来在反熵、其实一轮都没补"的假象）。

## 6. 风险

- **多一轮请求**（每台每轮一次 `/mesh/gaps`）：3 台 ≈ +3 请求/轮，可接受；但要在 §4 第 4 条里量一次 RTT；
- **"缺口"判错会把已同步的段再拉一遍**：幂等（拉过会 `superseded`/跳过），代价是流量，⛔ 不是数据损坏；
- **摘要口径写错会静默不补**（"同一份清单"永远为真）：⇒ 判据 2 必须覆盖"数量不同/首尾不同"两种假阴性；
- ⛔ **不许**把反熵当成"绕过 U4 裁决"的旁路。

# Obsidian vs 思源笔记 vs ShuyoNote

> 本地优先个人知识管理（PKM）三款代表产品的横向对比，以及 ShuyoNote 的定位、借鉴与差异化说明。

## 1. 一句话定位

| 产品 | 核心理念 | 数据形态 | 编辑范式 |
|------|----------|----------|----------|
| **Obsidian** | 本地 Markdown 文件 + 极强插件生态 | 纯 `.md` 文件 | Markdown（源码 / 实时预览 / 所见即所得） |
| **思源笔记** | 隐私优先的「块级数据库」 | JSON（块粒度） | 块编辑器（内容块为一等公民） |
| **ShuyoNote** | 本地优先的块编辑器 + 关系型知识工作台 | SQLite + Lexical JSON | 块编辑器（Notion 式） |

## 2. 逐维度对比

| 维度 | Obsidian | 思源笔记 | ShuyoNote |
|------|----------|----------|-----------|
| **数据可移植性** | ⭐⭐⭐ 纯 Markdown，可 git、任意编辑器可读 | ⭐⭐ JSON（自有格式，可导出 Markdown） | ⭐⭐ SQLite + Lexical JSON（可导出 Markdown / HTML） |
| **编辑器体验** | ⭐⭐ 偏文本，块能力弱 | ⭐⭐⭐ 强块编辑器（拖拽 / 样式 / 引用 / 嵌入 / 数据库） | ⭐⭐⭐ 强块编辑器（表格 / 媒体 / 块拖拽 / 斜杠菜单） |
| **块级引用 / 嵌入** | ⭐⭐ `^blockid`，基于行段落，较脆弱 | ⭐⭐⭐ 最强（`((id))` / `{{id}}` / 命名块） | ⭐⭐⭐ 已借鉴实现（`((id))` / `{{id}}` / 块级反链） |
| **双向链接 / 反链** | ⭐⭐⭐ 反链 + 提及 + 别名 | ⭐⭐⭐ 双链 + 反链（引用 / 提及） | ⭐⭐⭐ 页面双链 + 块级反链面板 |
| **关系图** | ⭐⭐⭐ 最成熟（全局 / 局部 / 过滤 / 分组 / 时间线） | ⭐⭐ 有，但较弱 | ⭐⭐⭐ 力导向 + 局部 / 缩放平移 / 标签属性过滤着色 |
| **属性 / 数据库** | ⭐⭐ Properties（YAML 类型化）+ 社区插件 Dataview / DB Folder | ⭐⭐⭐ 最强（内置属性 + 数据库块：表格 / 看板 / 画廊） | ⭐⭐⭐ 已实现（8 类型属性 + 数据库页三视图） |
| **扩展性** | ⭐⭐⭐ 2000+ 社区插件 + 主题 + CSS 片段 | ⭐⭐ 集市（插件 / 主题 / 模板 / 挂件） | ⭐ 插件注册表雏形（命令面板） |
| **同步** | ⭐⭐ Obsidian Sync（付费 / E2E）或 git / Syncthing | ⭐⭐⭐ 官方同步 + S3 / WebDAV + 端到端加密 | ⭐⭐ 自建 sync-server（outbox + LWW） |
| **多端** | ⭐⭐⭐ 桌面 + 移动 | ⭐⭐⭐ 桌面 + 移动 + Docker + Web | ⭐⭐ 桌面（Tauri）+ 浏览器 Web（同一前端），无原生移动端 |
| **开源** | ❌ 闭源（免费核心，部分付费） | ✅ 完全开源（AGPL） | ✅ 开源（AGPL-3.0，个人项目） |

## 3. 核心差异洞察

### 3.1 存储哲学是分水岭

- **Obsidian** 的护城河是「纯 Markdown 文件」——永不锁定、可 git、可移植、未来可读。
- **思源 / ShuyoNote** 是「结构化块存储」——编辑器更强、可做数据库查询，但格式锁定、可移植性弱于纯文本。

### 3.2 各自的能力上限

- **思源** = 「块级 + 数据库」能力的上限，是结构化知识的标杆。
- **Obsidian** = 「关系图 + 插件生态 + 文本可移植」的上限。

## 4. ShuyoNote 的定位：两者的中间路线

ShuyoNote 定位为「本地优先、Notion 式块编辑 + 轻量数据库 / 关系图」的桌面知识工作台，采用 Tauri 2 + Lexical + SQLite。

**借鉴来源**：

| 能力 | 借鉴自 | 落地 |
|------|--------|------|
| 块引用 `((id))` / 块嵌入 `{{id}}` / 块级反链 | 思源 | 块身份 `blockId` + `BlockRefNode` / `BlockEmbedNode` + 反链面板 |
| 关系图（局部 / 缩放平移 / 标签属性过滤着色） | Obsidian | `GraphView` 力导向图 + 块级图层 |
| 属性面板（Properties 式） | Obsidian | 页面标题下方可折叠键值编辑 |
| 属性 + 数据库视图（表格 / 看板 / 画廊） | 思源 + Obsidian | `attr_defs` / `page_props` + 数据库页（`kind=database`） |

**自研差异化**：

- **Tauri + SQLite + FTS5 中文检索**：比思源更轻（无 Go 后端 / 无 Docker 依赖），比 Obsidian 更「块编辑 + 数据库」。
- **自建同步**：outbox 变更日志 + LWW + 附件内容寻址，无第三方依赖。
- **本地优先 + 离线可用**：数据完全在本机 SQLite。

## 5. 选型建议

| 需求 | 推荐 |
|------|------|
| 纯文本、可 git、强图 + 强插件生态 | **Obsidian** |
| 最强块级引用 + 数据库 + 开源 + 移动端 + 加密同步 | **思源笔记** |
| 本地优先、Notion 式块编辑 + 轻量数据库 / 关系图 + 桌面单机 / 自建同步 | **ShuyoNote** |

## 6. 对 ShuyoNote 路线图的启示

- **短期**：补齐扩展性（主题 / 插件生态雏形）、Markdown 无损往返、端到端加密。
- **中期**：属性驱动的仪表盘聚合、移动端适配、PDF 导出。
- **长期**：社区插件市场（对标 Obsidian 生态 + 思源集市）。

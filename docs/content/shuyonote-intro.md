# ShuyoNote 数友笔记：本地优先的 Notion 替代，把生产力留在自己手里

> 一句话：**本地优先的类 Notion 生产力工具**——块编辑器 + 属性数据库 + 关系图 + 内置 PDF 阅读/批注/离线 OCR/AI，数据全部存在本机 SQLite，离线可用、无需订阅。开源（AGPL-3.0），可自托管同步。

## 你的生产力，不该被云端绑架

你的笔记、知识库、项目，如今大多躺在别人的服务器上——用 Notion 类工具，数据跟着账号走；用云同步，内容经过第三方。一旦平台涨价、倒闭、改版、封号，或者你只是想让某些资料**不出内网**，代价就来了。

**ShuyoNote 把数据放回你手里**：一切存在本机 SQLite，离线可用、无需注册、无云端依赖；Markdown 导出、整库备份、端到端加密，随时带走、随时自持。

## 它不只是"笔记"，是知识工作台

很多工具做了"编辑器"就止步。ShuyoNote 在这里做到了"全套工具链"：

- **块编辑器**（Lexical）：标题/引用/Callout/代码块/列表/待办/**表格**/分隔线等 12 种块；斜杠菜单、`+` 飞书式插入、**2–4 栏分栏**（每栏独立撤销）、块拖拽排序、块多选。
- **属性 + 数据库**：8 种属性类型 + **八种视图**——表格 / 画廊 / **看板（跨列拖拽）** / **日历** / 时间轴 / 目录 / **原生甘特图** / 列表；查询型数据库、保存视图、`ref` 关联、公式列、跨库 rollup。
- **块级引用 / 关系图**：`((块ID))` 引用、`{{块ID}}` 嵌入、块级反链；力导向**关系图**按引用类型着色，双链织网。
- **PDF 阅读 · 批注 · OCR · AI**：内置阅读器（连续滚动、护眼多档位）+ 高亮/画笔/便签/**摘录成块**（带 `pdf://` 回链）+ **离线 tesseract OCR**（双语完整模型，免联网）+ **AI 视觉识别** + **AI 一键生成目录** + 系统朗读。
- **AI 助手（可选、本地优先）**：可接本地 Ollama / OpenAI 兼容端点，**默认关闭**；语义检索、内联流式起草、侧边栏问答；写操作经确认，不越权。
- **公式 / 绘图**：`$…$`/`$$…$$` KaTeX 渲染（支持图片/手写识别公式）；Excalidraw 内嵌绘图、mermaid 流程图、AI 文生图。
- **管理学**：文件管理（文件夹=网盘）、模板、标签、多工作空间（**物理隔离**、可单独加密/备份/搬移）、回收站、版本历史、存储清理、插件（受限白名单运行时可扩展）、快捷键、命令面板、多窗口。

## 你会在意的事

- **数据安全**：本地 SQLite + FTS5 中文全文检索（中文子串/属性 `prop:` 语法）；内容寻址附件去重（SHA-256）；**端到端加密**（Argon2id + XChaCha20-Poly1305）；自动保存、版本回滚、回收站。本地优先，落盘可控。
- **离线可用 / 免费开源**：无需注册，断网照用；客户端 **AGPL-3.0 开源**。
- **可自托管同步**：多设备/团队用自建的 `shuyonote-sync-server`（outbox 增量 + LWW + 附件内容寻址），数据不出第三方。
- **全平台**：桌面（Tauri 2 + Rust）+ 浏览器 Web，同一套前端。

## 技术选型

Tauri 2（桌面壳，小体积、高性能、安全边界清晰）+ Rust（后端：SQLite/FTS5/PDF/搜索/加密/同步）+ React 18 + Lexical（编辑器）+ Vite 8。平台 driver 抽象：同一前端跑桌面与浏览器。

## 快速开始

```bash
git clone https://gitcode.com/shuyo-cn/ShuyoNote.git
cd ShuyoNote
pnpm install
pnpm tauri dev      # 桌面应用（或用 pnpm dev:web 跑浏览器版）
```

首次启动数据在应用数据目录（Windows：`%APPDATA%\cn.shuyo.shuyonote\`）。

## 它适合谁

- 重视**数据主权/隐私**、不想把笔记交给云端的个人与团队。
- 想要 **Notion 式块编辑 + 数据库 + 关系图**、但要求**离线、无订阅、数据自持**。
- 需要 **PDF 批注 + 离线 OCR + AI** 与**私有部署**（合规敏感行业：金融、医疗、政企、高校、研发）。

**对比**：Notion 强在云端协作，Obsidian 强在纯文本/插件生态，思源同属本地开源。ShuyoNote 的差异化是「**本地优先 + 块编辑 + 数据库（含甘特/看板/日历）+ 关系图 + 内置 PDF/OCR/AI/AI 助手 + 可自托管**」这一整套桌面工具链，把"笔记"升级为"知识工作台"。

## 开源与商用

客户端 **AGPL-3.0** 开源、免费；多设备/团队同步的 `shuyonote-sync-server` 为**独立商业授权组件**（私有仓库），用于自托管/私有部署。想长期用：个人免费开源、数据自持；团队可私有部署。

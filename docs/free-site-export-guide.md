# 免费客户出口 · 网站/帮助站导出与发布指南

> 一句话：ShuyoNote 是**本地优先 · 离网可用**的笔记工具，**免费/开源社区**的对外出口要做成「**可发现但克制、绝不阻塞、绝不跟踪**」的被动出口。本文说明这一侧的**内容从哪来、怎么导出、怎么发布**，与付费客户那侧的 [客户支持手册](customer-facing-playbook.md) 对应，但口径完全不同。
> 状态：**指南（落地）**。关联：[项目网站导航方案](plans/2026-08-27-project-website-navigation-plan.md)（外链入口/关于对话框）、[帮助系统方案](plans/2026-08-27-help-system-plan.md)（四层帮助）、[静态 wiki 导出（M21）](plans/2026-08-24-static-wiki-export-graph-plan.md)、[定位](positioning.md)。

---

## 1. 免费侧的三层出口

| 层 | 位置 | 内容 | 离线 |
|---|---|---|---|
| **P0 就地提示** | 应用内 | 命令面板 / 斜杠 / 占位符 / tooltip / 快捷键面板 | ✅ |
| **P1 内置帮助** | 应用内 | 内置「使用指南」页（= 可编辑笔记）+ 新手清单 | ✅ |
| **P2 外部静态站** | 应用外 | 深度教程 / FAQ / 版本说明 / 社区与反馈 | ❌ 仅补充 |

> **主形态永远是内置**（离线/可搜/可导出）；外部站只是「想深挖才去」，绝不成为核心路径，绝不因断网降级。

---

## 2. 导出 / 生成的三种方式

| 目标 | 方式 | 说明 |
|---|---|---|
| **帮助站（外部静态站）** | **复用 M21 静态 wiki 导出** | 把当前空间导成可浏览的静态 HTML wiki（双链/反链/标签/索引页），自托管 |
| **项目主页 / 文档站** | 手工建站 + 仓库 Pages（gitcode 等） | 主页偏**透明 + 文档 + 下载**，不引导注册/账号/云服务 |
| **应用内「关于」对话框** | 应用内渲染（`AboutDialog`） | 版本 / AGPL-3.0 许可 / 四干净链接 / 「禁用外部导航」开关 |

> **链接单一来源**：四个稳定 URL（项目主页 / 文档 / 发布 / 问题）由 `src/lib/links.ts` 定义，供「关于」/「检查更新」/帮助页脚注共用，**不散落硬编码**。

---

## 3. 链接策略（干净、无跟踪）

- 只链四个稳定 URL；**不带** `utm` / `ref` / 追参。
- **不埋点**：不因点击外链上报任何事件（隐私卖点红线）。
- **重定向**：站点迁移时靠服务端 301 保持旧链有效。
- **站点自控**：放在自己可稳定控制的域（或仓库 Pages），优先于第三方营销站。

---

## 4. 发布路径（建议）

1. **帮助站**：`M21 静态 wiki 导出` → 生成静态 HTML → 托管到 `仓库 Pages`（或自有域）。
2. **项目主页**：透明 + LICENSE + 下载 + 社区/反馈入口；防冒牌/防钓鱼。
3. **应用内**：「关于」对话框 + 四链接 + 「禁用外部导航」开关（`allowExternal`，持久化）。
4. **更新通道**：「检查更新」→ 发布页；版本自检（[自动升级方案](plans/2026-08-27-auto-update-plan.md)）。

---

## 5. 与付费侧的对照

| 维度 | 免费/开源社区 | 付费客户（B 端） |
|---|---|---|
| 出口/渠道 | 应用内被动出口 + 干净链接 + 公开 issue | sales@/support@/security@ + 企业微信 + 工单 |
| 触达 | 克制、不打断、不弹窗 | 主动（欢迎语/版本/续费/安全提醒） |
| 服务 | 尽力而为、无 SLA | 明确 SLA（P0–P3）、付费优先 |
| 导出 | 静态 wiki 帮助站 / 项目主页 | 客户支持手册（HTML/PDF 可分发） |

> 免费侧如需**可分发文档**（如致社区的一页介绍），可复用同款脚本思路：把 `.md` 用 `marked` 渲染成单文件 HTML。

---

## 6. 明确不做 / 红线

- ❌ 在线客服中心 / 应用内工单 / 打断式引导弹窗（免费侧的禁忌）。
- ❌ 带账号/注册/转化的营销落地页。
- ❌ 应用内埋点 / 外链跟踪参数。
- ❌ 把核心路径依赖到外部站（断网用户感知打折）。
- ❌ 站点漂移：外部文档与 App 版本脱节（曾出「快捷键清单不准」双源漂移）。**坚持从 `shortcuts.ts`/`guide.ts` 等单一来源生成或引用**。

---

## 7. 发布核对清单

- [ ] 应用内「关于」对话框：版本 / AGPL-3.0 / 四链接可达且 URL 干净。
- [ ] 「禁用外部导航」开关：关闭后外链不跳，离线照常；设置持久化。
- [ ] 内置「使用指南」页可离线、可搜索、可导出；页脚指向外部站。
- [ ] 帮助站由 `M21 静态 wiki 导出` 生成并托管（仓库 Pages / 自有域）。
- [ ] 无新增在线埋点：无网络上报事件。
- [ ] 外部站不可达时，应用内所有功能照常，不弹错/不降级。

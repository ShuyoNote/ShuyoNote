# 插件开发者政策（发布前请读）

> 适用范围：通过**索引**分发、或直接分享给他人安装的 ShuyoNote 插件（`examples/plugins/` 与第三方插件同一套规则）。
> 这份政策的篇幅刻意短：它说的是**底线**，不是风格指南。
> 相关：[插件分发策略](plans/2026-09-10-plugin-distribution-strategy.md) · [插件作者文档](plugin-api.md) · [可发布清单](plugin-recipes.md) · [安全政策](../SECURITY.md)

## 1. 应用不审核，也不假装审核

我们**没有人工审核**。索引是你自己订阅的（自托 = 自担），应用做的只是**把事实摆出来**：来源域名、权限与理由、
索引签名状态、发布者公钥指纹、静态扫描得到的事实（[事实清单](#5-应用会摆出哪些事实)）。

所以：**能装不等于可信**。不要在任何地方写"官方认证""已审核"之类的话。

## 2. 底线（违反会被撤回）

| 不许 | 为什么 |
|---|---|
| 偷取、外传用户笔记内容或附件 | 产品的整套设计（本机优先、E2EE、能力白名单）就是为了这件事不发生 |
| 声明与实际不符：偷偷做声明外的事 | 用户是**逐项**同意权限的；绕过它等于伪造同意 |
| 在 `manifest` 里伪造 `id`、冒充别的插件 / 作者 | 覆盖安装会直接毁掉别人的插件 |
| 用插件做与它宣称无关的事（挖矿、广告、刷量） | 用户装的是"一个功能"，不是一个宿主 |
| 收集使用统计并上报 | 分发策略明令禁止埋点/下载计数/排行榜；「评价」走社区帖子（`discussionUrl`） |
| 用 `eval`/混淆把真实行为藏起来 | 不是禁止动态代码，而是**禁止藏**：这类写法会被事实清单标出来，用户看不懂就会不装 |

**可以**做而且欢迎：读写笔记的能力、生成草稿、导出文件、声明式视图与主题、把无聊的整理工作自动化。

## 3. 必须写的三件事

1. **许可**：索引的 `license` 字段必填（AGPL 环境下的分发义务，至少要说清是什么许可）。
2. **权限理由**：每一项权限都要写 `reason`，用**用户能读懂**的话说明"为什么需要"。写得含糊会被拒装（应用强制）。
3. **变更说明**：新增权限或事件时，用户会看到一次「需重新确认」（插件在确认前**暂停**）。发布说明里提前讲一句，
   比让他自己发现要好。

## 4. 撤回与下架

- **撤回某个版本**：索引里给该条加 `revokedAt`（附 `revokedReason`）。应用会记住它——**运行与安装两条路都会拦，
  离线也生效**；用户仍可显式「仍然使用」，所以**原因要写清楚**（那是他做判断的依据）。
- **撤回一把发布者密钥**：索引顶层 `revokedKeys`。这是很重的动作——它否掉的是"这把 key 签的一切"。
  只在密钥泄露、被滥用、或你彻底放弃这把 key 时使用。
- **换密钥**：应用会把用户第一次装成功时的那把 key **固定下来**（TOFU）。换 key 之后，老用户那边会**拒绝安装**
  并看到新旧两个指纹。所以换 key 时**必须在发布说明/社区帖里公示新指纹**，让用户能对着公告核对——
  否则这次升级在他眼里就是一次可疑的密钥变更，而且他这么认为是对的。

## 5. 应用会摆出哪些事实

用户能在「插件管理 → 事实」里看到（这些是**事实**，应用不替用户下结论）：

- **来源**：本地文件夹 / zip 包 / 索引（域名）/ 随应用附带；
- **体积**：目录大小、文件数、入口文件大小；
- **声明**：权限清单（含风险等级）、是否走了"旧 manifest 没声明权限"的基线授权、订阅的事件；
- **静态扫描**：出现 `eval(` / `new Function(`（会在运行时构造并执行代码）、大段连续编码文本（内嵌资源或打包产物）、
  超长单行（压缩后的代码）、看起来在联网的写法（**本版本插件没有任何联网能力**，所以那只会是死代码）；
- **运行记录**（「活动」面板）：它调用过哪些能力、有没有被权限拦下、每次运行的结局与**峰值内存**；
- **撤回状态**：这个版本 / 这把密钥是否被索引撤回过，以及你是否选择过继续使用。

这些都不构成"安全"或"不安全"的结论。一个**没有**任何事实的插件也可能有问题；一个**有** `eval` 的插件也可能完全正当。
应用能保证的是：**它不许插件悄悄做别的事**（能力白名单 + 逐次权限校验 + 写操作出草稿 + 子进程隔离）。

## 6. 报告问题

发现插件有问题（恶意、越权、冒充、失效）：走 [SECURITY.md](../SECURITY.md) 的渠道，不要直接开公开 issue 贴利用细节。
